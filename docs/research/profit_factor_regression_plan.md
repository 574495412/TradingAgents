# 量化回归与因子评分：第一版冻结设计

2026-10-16，按用户更新的目标“用量化回归去做，市场上有评分标准”执行。
本设计在本轮回归、未来收益标签和评分计算之前固定。它是因子研究，不把相关性、回归拟合或小样本统计当作可上线收益。
原24小时模拟、同期观察及15分钟技术窗口不改写；原失败候选保留。

## 文献口径与决策

采用逐时点截面回归、跨时点系数汇总的Fama–MacBeth思路，另报Pearson IC和Spearman Rank IC。
系数及IC先按UTC日取均值，再使用固定3日滞后、Bartlett权重的Newey–West均值标准误，报告双侧渐近正态p值和t值。
短历史只有15个已使用交易日、另1个此前未计算收益的后续日，因此显著性只是探索性描述，不能称充分样本。
同一批所有单因子Rank IC检验合并作Benjamini–Hochberg校正；不在大量检验后只报告最优p值。
没有通用的“IC必须大于某数就能盈利”标准，不设武断合成总分。评分表分列预测性、独立增量、时序泛化、成本与执行资格。

参考：[Fama与MacBeth原论文](https://www.journals.uchicago.edu/doi/10.1086/260061)、[Newey与West原论文工作稿](https://www.nber.org/papers/t0055)、[多重选择与膨胀Sharpe](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)。
Sharpe与Calmar只应来自完整连续扣费账户；本轮截面收益差不伪装为此类账户，也不计算无法证明完整试验次数的Deflated Sharpe数值。

## 数据、样本和时间

使用已封存公开分钟原文，固定原748合约，按预定资产类别分为加密永续与TradFi永续分别回归。
原清单由后来合约状态取得，历史上市资格只按当时已知日期约束，仍有存活及历史资格偏差；不删除失败或无数据成员来美化覆盖。
历史训练2026-09-29至10-06 UTC，回顾性验证10-06至10-14 UTC；两段此前已用于策略研发，不称独立样本外。
此前隔离的10-14至10-15 UTC只做本轮首次后续日检验；它仍是事后下载的档案，仅一天，不能称真实前向或独立长期复制。
每个整UTC小时t取一次截面，因子仅用t及以前结束的完整分钟；假定至少等一分钟到t+60秒开盘作标签起点。
主标签为随后20分钟的开盘到开盘简单收益，60分钟为预定稳健性标签；小时抽样避免同一标签区间重叠。
每个标签的起止开盘必须在同一训练／验证／后续日区间内，边界样本清除，不让训练目标读入验证时段。
全部未来标签保持单独列，不参与特征、排名、因子缺失判定或训练权重。
分钟缺口不前向填价；特征按完整连续窗口计算。每时点先按已知特征确定排名，再核对后续标签缺失，不能按未来可用性重排交易组。

## 固定因子和回归

第一版先覆盖两套策略共同依赖的5个方向因子：3分钟收益、20分钟收益、60分钟收益、3分钟主动买卖金额差占比、12分钟主动买卖金额差占比。
收益因子为自然对数价格变化，流量为`2*sum(taker_buy_quote)/sum(quote_volume)-1`，零总量保留未知。
另以60分钟已实现收益波动及60分钟成交额对数作为控制变量，不能将控制项事后改名为新候选。
全部特征按同一时点、同一资产类别的完整特征成员作平均名次，再中心化至[-0.5,0.5]；无监督截面处理不读未来标签。
每时点至少20个有效成员。先做每因子单变量回归与IC，再做固定5因子加两控制项的多元OLS；矩阵秩不足时整个多元截面记失败，不事后删相关因子取得显著性。
多元训练系数只取训练期逐小时系数均值，验证与后续日不重估、不改方向、不选超参数；报告相对零超额收益预测的样本外R²和预测Rank IC。
因子方向只用训练Rank IC均值确定，之后固定。每时点最高与最低各20%成员形成等权诊断组，依训练方向决定正负。
诊断组总绝对权重为1（两侧各0.5），报告毛收益差及16／30bps完整换仓成本压力；这些只是固定名义权重的标签诊断，不含真实盘口、资金费、数量约束与路径复利，不能称净账户收益。
选组后的未来标签若缺失，整个该时点组收益记未知，不缩小组别；固定小时区间独立，不假装执行了完整策略。

## 覆盖、证伪与后续

保存每个预定截面、每个因子的有效数、缺失数、重复键、时序边界、秩不足、原文件SHA和完整逐时点结果。
原始分钟的价格、量、买方金额、结束时间和重复时钟均核验；保存运行源码、依赖、标签生成与回归数据，便于重建。
基差、持仓量与资金费扩展需要全量、事前固定依赖；旧指数／OI档案按价格冲击抽取，直接拿来做无条件截面会有选择偏差，因此本版不把这些选择性覆盖加入共同回归。
第一版排名不授予生产资格。候选须在独立足量区间、固定连续账户、真实费用、共享容量、压力成本和原稳定性门槛下再验证，稳定后才接入独立生产策略。
