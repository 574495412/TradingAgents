# 量化回归与因子评分首轮结果

2026-10-16。已按用户更新的目标转为量化回归研究：固定因子、训练方向与系数，分别检查排序预测、独立回归、后段泛化及成本幅度。
目前看到部分短期反转关系，但没有可晋级的盈利因子；不能以显著IC、t值或拟合成功冒充扣费账户收益。
本轮没有改原运行策略，也没有接入生产。

## 采用的常用评分口径

| 层面 | 评分／检验 | 本轮判断 |
| --- | --- | --- |
| 排序预测 | Pearson IC、Spearman Rank IC、日均IC／日标准差 | 部分反转方向存在，因子与期限间不稳定 |
| 回归关系 | 单变量及固定五因子加两控制项的逐小时OLS | 全部1530个截面完成，非零斜率不等于可交易收益 |
| 时间依赖 | 日均值、Newey–West固定3日滞后t和渐近p | 只有7／8／1日，仅可探索，不作稳定显著性证明 |
| 多重比较 | 所有有效Rank IC检验的BH校正 | 60项预定检验中40项有p，保留日不算t；因子相关使独立性条件不足 |
| 泛化 | 固定训练系数预测Rank IC及相对零超额收益预测R² | 验证四组R²全部为负 |
| 经济幅度 | 固定20%两端组毛标签差、16／30bps换仓成本敏感性 | 全部60项阶段结果两种成本敏感性均为负 |
| 交易绩效 | 连续账户Sharpe、Calmar、净收益、胜率、回撤与资金费 | 本轮未建立该账户，不伪造或套用评分 |

逐时点截面系数汇总借鉴[Fama–MacBeth](https://www.journals.uchicago.edu/doi/10.1086/260061)，时间相关标准误采用[Newey–West](https://www.nber.org/papers/t0055)。
多重检验参考[Benjamini–Hochberg](https://academic.oup.com/jrsssb/article/57/1/289/7035855)；本轮相关因子、小样本和历史复用意味着q值只供探索。
[Deflated Sharpe](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)强调选择次数与非正态的影响；没有完整净账户与可核实的全部历史试验次数时，本轮不报一个貌似精确的DSR。
业内方法并不提供统一的“IC超过某数就可上线”保证，所以不造0—100合成分数，也不事后修改门槛。

## 固定数据与时序

协议及源码在标签与本轮结果计算前封存于v093，详细定义见[事前设计](profit_factor_regression_plan.md)。
固定748个合约，分528个加密永续、220个TradFi永续；核验12716份原始公开分钟，生成287232行合约小时样本。
完整特征小时数为加密201927、TradFi64771；预定样本不删掉缺失，不用未来收益可用性重排成员。
因子为3／20／60分钟价格收益与3／12分钟主动买卖金额差占比；控制60分钟已实现波动及成交额对数。
基差和持仓量的旧依赖按价格冲击选取，存在覆盖选择，因此未混入这轮无条件共同回归；后续扩展须先固定全量依赖。

每整UTC小时t用此前已完成分钟构建特征，标签从t+一分钟开盘至随后20／60分钟开盘。
同资产类别内按当时完整特征成员作平均名次变换，特征不读未来标签；训练标签不得跨入验证阶段，选组后缺标签则整个组收益未知。

| 阶段，UTC右侧不含 | 日期 | 用途与限制 |
| --- | --- | --- |
| 训练 | 09-29至10-06 | 此前已参与研发，确定方向及平均回归系数 |
| 回顾验证 | 10-06至10-14 | 此前已参与研发，只检验本轮冻结方法的后段表现 |
| 隔离后续日 | 10-14至10-15 | 本轮首次计算收益，只有一天，仍是事后档案而非实时前向 |

旧清单来自后来状态，历史资格与存活偏差未消除；档案不证明历史首次公开及接收时刻。
这些限制会影响结论，完整复核不能将其自动消除。

本轮控制项已进入多元模型，但尚未单独冻结控制项基准及逐因子剔除对照，不能据斜率就宣称独立增量。
