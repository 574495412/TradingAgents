# EXAS：从原始并购文件到可用现金的生命周期核查

本案例只深入已固定的EXAS，不增加股票、因子、参数或经济账户。**后续已取得64个缺失交易日的供应商候选数据，但重叠核查有冲突，尚未准入；并购现金何时可用仍未证实，长窗口继续阻断，50%/15%目标未达标。**

## 现金权利不等于可以买入下一只股票的资金

原始协议第3.1条区分了持股形态：电子记账持股无需递交纸质股票或转让函，付款方须尽合理努力尽快支付，但没有给所有账户统一固定到账日。纸质股票则需要交回股票或相应遗失声明及所需文件。

协议中“五个营业日”的要求是向纸质股票持有人邮寄办理材料的期限，**不是所有股东付款或券商到账的期限**。员工股权奖励的工资发放安排同样不能套用到普通股。

每股105美元是符合条件股份的毛现金权利，仍需考虑适用代扣、费用和账户持有资格；无利息。付款代理已获资金、法律权利成立、券商记账、价值日和可用现金是不同事实。没有目标账户的外部凭证时，不将普通卖出三交易日资金锁当作并购实际到账依据，也不虚构一个保守天数来恢复长窗口净值。

HistoricalData.net公开覆盖API确实返回`EXAS_day_delisted_2026-03-24.csv`，声称文件首尾日期为2003-10-01至2026-03-20。这与停牌日期/末次交易日的区别相容，但**文件目录首尾边界不是64日完整性、证券身份、正确价格或成交能力的证明**。本轮未取得该文件任何行情行。

其本次公开目录列示日线历史包单用户199美元、一次性购买；尚未购买。目录不是采购授权、合法访问凭证或供应商质量认证，亦不构成推荐。若采用该路线，还需核对许可证，外部复核者须有自己的合法访问权，不能默认可向第三方分发数据。也可使用满足同一要求的其他合法原始数据。

[缺失输入契约](missing-input-contract.json)固定了取得数据后必须检查的内容：64个缺失交易日，加两端各10个重叠交易日，共至少84个实际日线记录；原始未复权OHLCV、证券/类别身份、来源/版本/许可、公司行动及所有跨源差异。重叠价格容差预先固定为每股0.01美元以容纳旧浮点表达；成交量差异必须逐项解释，不平均、不静默择源。目录覆盖声明不能通过这份契约。

并购资金另需券商/托管方原始交易ID、影响股数、毛额/代扣/费用/净额/币种、记账时间、价值日和可用时间。当前所有实际到账时间保持空值。若无法取得，仍可记录“现金应收未核实”的研究限制，不能宣称完整可执行长窗口或真实绩效已验收。
