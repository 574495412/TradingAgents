# 因子独立增量：控制项和剔除检验

2026-10-16。七模型对照已完成，结论进一步收紧：五个方向因子整体没有在多数验证组提供预测增量，且所有模型的成本敏感性仍未达到经济可行性。
本轮不据剔除结果事后选一个收益赢家上线，后续搜索转向事前全量的基差与持仓变量。

## 固定设计与范围

七个模型为仅60分钟波动及成交额对数、完整五因子加两控制项、分别去掉五个方向因子的五个模型。
全部模型共用同一七特征完整成员和标签行，特征排名、训练日期、小时标签、成本敏感性和后段边界保持首轮口径。
模型斜率均只由训练期逐小时OLS估计后取均值，验证与后续日不重估；矩阵秩不足不临时删列。
完整模型的训练系数和所有阶段R²与v093在浮点容差内相同。

该设计在增量结果计算前冻结于`profit_factor_incremental_plan.md`，但所有历史和10月14日已在v093使用，因此本轮是补充诊断，不能再称新增样本外。
沿用两资产类别、20／60分钟、7／8／1日三个阶段，共72个预定MSE增量检验；48项有渐近p，一日阶段不计算显著性。
三日Bartlett HAC和探索性BH校正未改变，相关模型与小样本限制继续适用。

## 预测增量结果

`ΔR² = R²完整 - R²控制项`，使用相同预测成员的累计平方误差；正值只表示相对基准误差更小，不代表盈利。

验证只有TradFi的60分钟组相对控制项改善，但改善幅度很小，配对检验未给出有力证据，完整模型自身相对零超额收益预测的R²仍为负。
加密20分钟的负t和小q表明本口径下完整模型相对控制项更差，不能把较小p值一概理解成好因子。
训练四组的ΔR²都为正而多数后段变负，提示训练拟合优势没有稳定延续。

后续日TradFi60分钟的累计ΔR²为正，但按小时等权再按日平均的MSE改善约-1.99e-9，为负。
两者并不矛盾：累计SSE隐含按有效成员数加权，小时均值则每时点等权。本轮两个口径都报告，不挑有利指标。

## 剔除诊断

`剔除模型MSE - 完整模型MSE`为正才表示在该对照内加入该因子改善预测，不能理解为因果效应。
例如验证20分钟时，完整模型相对两资产类别的`without_return_60m`模型的ΔR²分别约-0.00007583／-0.00051288，表示去掉60分钟收益反而较好。
TradFi60分钟时，完整模型相对去掉20分钟收益的模型ΔR²约+0.00042396，表示加入该因子在这个模型组合中改善误差；同组相对去掉12分钟流量的模型却约-0.00027605。
这些符号随资产、期限和阶段变化，没有依据从某一组合直接选“稳定盈利因子”。
