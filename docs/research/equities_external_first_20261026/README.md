## 如何判定完成

|层级|验收|决策|
|---|---|---|
|收益模块|先冻结机制、适用/禁用域、周期与失效；比较同机会集的扣费优势、完整周期PnL/尾部及成本压力。30周期/4入场月簇只是最低计数，相关性仍须验证|有证据再进入配置研究；不要求每个模块全年50%；样本不足为未知|
|配置/风险|相同模块集的静态分散、风险分配、有限调权与移除消融，统一本金、库存、净额成交及切换费；比较实际风险|风控按减损及损失上涨机会验收，不要求独立正PnL|
|多策略总账户|至少两个有独立经济证据的机制、100完整周期、PF>=1.15、闭合PnL正；双成本、目标资金、跨年/JSON恢复、独立样本及真实风险证据齐全|同时检验50%扣费年化、15%回撤、夏普1；任何关键项未知不能报达标|

年化是含可执行退出准备的终值几何年化，不用短窗均值。股票夏普252、加密365，原币分别算。收盘、日低价包络与精确盘中回撤分列；日线包络不认证15%盘中上限。当前挑战账户实际值为null，既不把旧静态账户当挑战组合，也不把新策略的累计收益冒充年化。

## 外部来源优先级

先找可解释、可审阅且数据能支持的外部策略，固定来源/版本/许可，再复现；仅针对可定位失效机制做有限自研。不按GitHub星数、营销年化或基金名气挑赢家。完整目录及原始抓取状态见 [sources.json](sources.json)。

1. **Faber月末趋势与风险消融**：首轮已完成。作者公开的10个月总回报趋势规则有明确更新时点，适合先检验低换手假设。[作者原文，20—21页](https://mebfaber.com/wp-content/uploads/2016/05/SSRN-id962461.pdf)。
2. **AQR/PST趋势与横截面动量**：复用既有数学与波动/排名工程；股票需更广的PIT成员、退市与停牌数据。时间序列与横截面动量分别评价，不算两个参数版本就是两个独立alpha。[AQR原文](https://www.aqr.com/insights/research/journal-article/time-series-momentum)。
3. **AQR质量/价值与ARK公司论点**：PIT财报、历史假设、股数和当时估值齐备后，才预登记回测。质量、估值及主动主题不是同一机制。[AQR QMJ](https://www.aqr.com/insights/research/working-paper/quality-minus-junk)、[ARK投资流程](https://www.ark-invest.com/investment-process)。
4. **盈余/公告后漂移及事件风险层**：先完成论文筛选和真实发布时间/可用延迟、实际盈余与当时预期数据；SEC仅为原始披露来源，不能把“找到了SEC”当已复现事件策略。
5. **加密carry/动量与NFI参考**：复用因果排名、持仓缓冲、净额化、费用/资金费拆分及完整账户审计；永续资金费不作为股票收益。原生经济验收由Freqtrade及原研究责任域负责，当前不额外开加密网格。
6. **关系回归/配对**：复用形成期冻结、关系失效和双腿账本；股票短腿需借券可得性/费率及历史企业行动，未验证时禁用。

官方基金研究分工：[Man AHL](https://www.man.com/ahl)参考多机制/执行/独立风险；[AQR](https://www.aqr.com/insights/research/journal-article/understanding-style-premia)参考风格溢价；[Two Sigma](https://www.twosigma.com/businesses/investment-management/)参考研究分工；[Bridgewater](https://www.bridgewater.com/research-and-insights/the-all-weather-story)参考环境风险结构。未据此给基金做业绩排名，也没有把公开方法当私有策略全量复制。

ARK是主动主题与公司估值参考，并非通用量化择时基金。其[FAQ](https://www.ark-invest.com/faq)说明环境偏好与论点纪律。本轮由ARK官方文章链接核对其Tesla公开模型，固定仓库commit `648381537eefc0a64518729bcff2ac4e24b0dd1a`；README当前为2031模型及Monte Carlo情景，不是基金账户回报。README限制商业使用，当前只读方法，不复制或执行该模型。没有TSLA的PIT历史输入，不生成虚构收益。[固定README](https://github.com/ARKInvest/ARK-Invest-Tesla-Valuation-Model/blob/648381537eefc0a64518729bcff2ac4e24b0dd1a/README.md)。
