静态方案各模块0.4预算，未激活预算留现金；风险分配用过去20交易日波动率做标的逆波动权重、12%保守波动上界缩放，不向上加杠杆；有限状态用当时基准收盘/SMA200调趋势及恢复预算，再叠加风控。消融移除一个模块后保留其现金预算，不把剩余模块放大成满仓。模块与配置权重先净额化，再在同一个本金/库存/现金账户成交；所有切换成本进入账本。

## 真实数据和账户规则

复用 `data/research/equities_hkus_20261024_v006/`。规范化与原始行情、事件和日历17份文件SHA-256重验通过；US每标的2198行，HK2152行。沿用 exchange_calendars 4.13.2 与既有港交所临时休市/延迟开市修正，继承DST、半日、重复、缺失和分拆拒绝检查。哈希一致只能证明封存字节一致，不能认证供应商真实性。

- 收盘信号在次一实际交易日开盘成交；价格加不利滑点。US整数股、2800.HK每手500。完整历史整手规则仍待认证，分拆事件直接拒绝，不套用错误历史股数。
- 原币现金分账，不做FX、借券、短仓或杠杆。按计划净目标股数交易，前一交易日收盘权益5%的免交易带不阻止完整退出。交易量最多使用过去20期平均日量的0.1%，不读当日未来成交量。
- 卖出款锁定3个交易日，加入待结资金队列；同日卖出款不能资助买入。它是研究缓冲，并非经认证的银行结算日历/券商购买力。真实T+1/T+2规则和银行假日尚未精确建模。
- 除息前持仓获得应收股息；除息日开盘卖出仍有权，新买入无权。应收款从不再投资，未知派息日不造现金；US30%扣减是研究情景，HK假设0。未包含未经验证的券商派息收取费，不能把账本当作完整真实券商税后结单。
- 佣金为US1bps最低1 USD、HK3bps最低15 HKD的冻结研究情景，不是长桥报价。US卖出SEC及TAF按历史生效日，HK单列SFC/AFRC/交易/结算费与ETF印花税豁免；US传导费用向上取分、HK相关费用四舍五入。SRO charge date与券商trade date的映射仍为代理。
- 期末不强制虚构成交，持仓标记估值并单列浮动损益、未闭合周期PnL和退出准备。部分减仓不算多个盈利周期，仓位归零才形成完整生命周期。胜率计入该周期买卖费用、滑点和已归属股息。

10倍资金对照下，静态组合高成本US收益26.57%、风险包络6.82%；HK收益5.72%、风险包络12.99%。这两档静态账户没有触及日量上限，但没有盘口、开盘竞价、市场冲击或腾讯量纲的独立认证，**不能据此认证10万USD或100万HKD容量**。整数手与最低费造成小资金效率差异，不能误称新增策略能力。

## 连续性、独立复算和分期归因

所有56账户的52,024个收盘权益时点、4,434笔成交经独立Decimal重建；不导入账户引擎，逐项核对可用现金、待结现金、应收、份额、股息归属、成交价、分项费率、剩余成本、完整周期和高水位回撤。最大余额绝对差6.775e−10原币。财务一致不等于数据或可成交认证。

每个账户先运行2023—2024并写出真实 `checkpoint.json`，再由新的Python解释器加载JSON、恢复2025—2026，与完整连续运行逐字段比较，56/56完全一致。24个检查点持有库存；跨年检查点没有未结现金，因此另从真实US/HK行情选择两处待结卖出款边界，在新进程恢复全部剩余历史，亦完全一致。风险停机与冷却连续性由受控测试验证；真实账户未触发，相关真实证据仍未知。

`period-diagnostics.json` 为独立的只读分期归因：完整自然年、连续90自然日块、前一交易日可见的环境；保留全程库存和高水位。逐组提供净收益、夏普、连续高水位回撤、退出归属的周期数/净胜率/PF/闭合PnL、费用、滑点、换手和敞口。56账户的年度复合收益、周期数和费用均与总账户核对。环境条件分组并非可独立交易或拼接的账户；缺事件源标unknown，不补零。

静态组合高成本年度净收益：US 2023/2024/2025/2026截至9月分别+6.67%/+7.38%/+4.93%/+2.39%；HK分别−5.74%/+12.48%/+5.31%/−5.78%。这些差异进一步说明不能只凭一个赚钱窗口认定跨环境稳定。

## 尚未证实及下一轮边界

1. 先补权威股息/拆并股/历史整手、付款/结算日历、真实券商只读鉴权与收费收据，再谈认证股票账户。当前公开行情不能称长桥成功认证。
2. 股票池扩展须先登记历史成份、退市、停牌、量纲及可用时点；不能按今天的流动性筛池后宣称历史无偏。
3. 横截面动量需更广且有历史成员资格的池。价值/质量需PIT财报、修订版本与发布时间；事件模块需原始公开时点与可用延迟。缺数据阶段不生成人造因子收益。
4. 收益模块先按适用机会集相对现金和可执行权益基准的扣费优势检验；配置再匹配实际风险、做覆盖层有/无消融。当前不足两类已验证独立机制，不凑多策略数量。
5. 下一轮协议在任何新评估前冻结；2025/2026不得重命名独立样本外。维持原失败记录，不刷本组参数；无下单、部署、推送或生产变更。
