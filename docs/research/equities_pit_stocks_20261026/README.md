## 多策略和加密组合的当前结论

本轮确实执行了同资本、同账本的股票动量/质量各半组合，结果为负且回撤超限；没有凭单策略赢家拼装总账户。模块至少30周期、组合至少100周期等门槛未通过。

另核对原任务完成的时点池修正加密研究：54个账户中的48个策略账户全部负收益，6个现金对照不算收益源，容量追加候选为0。此结论只适用于该研究包；不推断所有加密机制或CZ独立生产策略无效。匹配现货/永续双腿研究仍归原任务推进，没有将尚未完成的研究当成收益证据。

更基础的约束也未满足：本轮股票可评估历史止于2024年6月，所查加密账户从2025年开始，没有共同已评估时段；USD/USDT也缺乏已核实的兑换、共同保证金和资金约束。`combination-admission.json`记录 `NOT_ADMITTED`，组合收益、回撤、夏普保持null；没有通过加权独立净值曲线制造跨资产账户结果。
