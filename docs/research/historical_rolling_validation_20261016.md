# 历史滚动训练验证

用户已取消强制未来两段三十日前向，并明确有稳定量化策略即可推进上线，不需要研究很多天。本版按质量验收，不设最低研发天数；真实前向观察保留为可选补充。[当前冻结计划](../../tradingagents/research/quant/plans/historical_rolling_plan.md)已替代旧计划的强制等待安排，旧实验和当时结论原文保留。

本轮实现和执行了历史扩展训练及全部72条连续账户，尚无账户通过原项目经济筛查。原资金费双因子组合在三档成本下仍盈利，但重训版只有26条平仓腿、8个批次，后三块没有新成交。当前不能认定已形成稳定候选，原因不再包含“缺少未来六十日”。

## 方法与复算

输入复用已封存的 `settled_funding_20261016_v001`，训练起点固定为2026-09-29 UTC；在10月6、8、10、12日零点重训，各自应用两日。训练标签须满足 `t+(h+1)分钟 < 重训边界`，原阶段边界的NaN保留；先按九项共同已知特征排名，再筛已知标签。五模型共用全部可拟合小时，逐小时普通最小二乘斜率等权平均。

两个资产类别、三个期限、四个交易模型、三档滑点形成72条独立账户。本金、持仓、资金费、等待入场及风险状态跨块延续，只在原总终点退出；没有每两日重新投入1000本金或拼接模型赢家。单边手续费5bps、滑点3／10／11bps，其余规则沿用原账户。

新增入口为原 `forecast` 命令的 `--historical-rolling`：

```sh
tradingagents-quant forecast \
  --source results/research/settled_funding_20261016_v001 \
  --market-panel data/research/dual_alpha_native_fusion_20261015/full_omofun_market_001 \
  --funding-root results/research/profit_factor_search_20261015/public_v001 \
  --output results/research/新的独立目录 \
  --historical-rolling
```

新结果位于 `results/research/settled_funding_rolling_20261016_v002/`。`protocol.json`记录计划、完整包源码与来源身份；`rolling_training.json`保存全部系数、训练时刻与失败诊断；全部决策、72条压缩账本及收据保留。决策路径只读取特征白名单，训练标签单独读取，不进入交易成员筛选。

## 全部账户结果

共11,521分钟帧，72条账户均完成独立财务重建，0条数值失败，期末全部空仓。60条无成交，12条活跃；活跃账户全部属于加密240分钟，其他资产及期限不以零收益计作通过。

下表为完整8日连续账户净收益，已包括手续费、滑点和实际资金费，单位为百分比。

| 加密240分钟模型 | 3bps | 10bps | 11bps |
| --- | ---: | ---: | ---: |
| 原七特征基线 | −0.492423 | −0.597434 | −0.612429 |
| 追加24小时资金费 | −0.112724 | −0.182122 | −0.192034 |
| 追加资金费日变化 | −2.974844 | −3.518650 | −3.596105 |
| 追加两个资金费因子 | +1.830776 | +1.376751 | +1.312042 |

原已识别双因子候选在固定训练版的对应收益为+8.001427%／+6.290404%／+6.048146%；滚动版均减小。这是两种完整规则的配对历史诊断，不代表全部差值都来自某一个时点或单一因子，也不证明固定系数策略必然失效。

滚动双因子10bps账户终值1013.767513、利润因子1.475047、最大含浮亏回撤2.833213%、平仓腿胜率50%、Wilson下界32.060306%，实际资金费为−0.569119。26条腿来自8批次，其中5批次净盈利；这些数量不能自动视为独立同分布样本。四块权益收益为+1.376751%、0%、0%、0%，全部成交和利润集中在第一块，后三块没有新机会或成交，账户没有因风险停止而跳过交易。

本轮不新增“每块必须盈利”门槛。沿用完整区间至少30条平仓腿、Wilson下界至少40%、利润因子至少1.1、回撤低于8%及正收益等原项目筛查，全部账户均未通过。这些是项目既定筛查口径，不声称为行业统一标准。原固定版压力胜率下界约36.88%，也未通过原40%要求。

每块摘要保存连续权益、费用、模型滑点拖累、实际资金费、开平腿、起终批次、机会、拒绝、方向／品种计数及边界真实账户状态。分块按现金流进入曲线的处理分钟归属，避免开盘成交钟与曲线处理钟差一分钟导致错归；四块损益合计与整段权益一致，跨块持仓以浮盈亏计量。

## 验证及边界

201项相关测试通过，新增代码通过Ruff与格式检查。测试覆盖首轮系数复现原估计、标签恰好到边界仍剔除、未来标签和特征扰动不影响此前系数、单模型秩失败后五模型共同剔除、原NaN不可补写，以及重训换方向时原持仓不被清账。人工边界测试逐块核对费用与滑点对权益的贡献，不能由总额相符替代归属正确。

独立计算复核7,790次逐时OLS、816个冻结斜率，误差为0；首轮与原固定训练系数精确一致。72账户的288个分块权益、费用、资金费、腿／批次及边界状态均独立核对通过；此分块审计没有另外重跑完整逐分钟财务重建。脚本和收据保存在 `results/research/settled_funding_rolling_audit_20261016_v001/`。第一次分块版本 `settled_funding_rolling_20261016_v001` 原样保留；其现金流按成交钟归属的边界差异在本次真实数据没有触发，两版完整原始账本精确一致，指标仅新增现金流时钟说明。两组账户和独立审计的263／263／2个封存文件重新核验通过。

这些历史已经多次用于研发，本轮不是新增独立样本外。原固定模型的预测增量仍未得到可靠支持，本轮不以账户盈利替代预测证据。资金费五分钟可见延迟仍是研究假设；连续数量、固定滑点、历史首次到达、历史成员及规则完整性未被证明。已找到包含全部748合约过滤器的原始交易所快照，但捕获晚于账户区间，只能用于另行冻结的静态规则敏感性复算。

上线按候选是否达到经济、执行和运行要求推进，不追加真实前向或最低研究天数。当前研究继续留在TradingAgents；达标后再以轻量策略接入CZ-Agent，保留独立状态、风险、迁移与回滚。当前结论不构成已部署记录。
