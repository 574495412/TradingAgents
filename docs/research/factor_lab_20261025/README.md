# 统一因子、宏观新闻与HTML组合：本轮结果

2026-10-25。当前源码统一位于 [factors/](../../../factors/README.md)，整体职责见 [RESEARCH_STRUCTURE.md](../../../RESEARCH_STRUCTURE.md)。本轮不是仅补规划：74个因子、12个预测模型和64个账户已运行；独立审计和浏览器交互已验证。源码、冻结计划及轻量结果随本版提交，大行情、数据库及完整五分钟账本保留在本地研究目录。

## 范围与速度

- 74个活跃因子，覆盖技术、趋势、风险、流动性、市场横截面、资金费、官方宏观新闻和固定交互。包含 RSI、MACD、布林、ATR、ADX、CCI、MFI、Williams %R、OBV 等常用指标。
- 同一套共同计算层支持股票实际交易日历，股票适配输出69个共同因子，资金费等5个专属列被排除；这证明公式接口可共用，不构成股票收益验证。
- 195份历史源码／元数据在统一目录按SHA256登记，原TA研究路径保留导入桥；CZ现有执行因子保留为冻结版本。文件数不是独立因子数，74个相关列也不是74个独立alpha。
- 22份FOMC官方声明保留原文摘要身份与实际公布时间，内容从公布后5分钟起可用。支持固定词典分数、利率中点与变化、事件衰减和交互；CPI档案HTTP403和缺少一致预期差保持明确缺口，不假造新闻。
- 2024训练；2025四个季度、2026前三个季度，各取固定前28天，共7窗。时段按日历冻结，BTC涨跌与深回撤标签只做事后环境描述，不按策略收益选择。过去可用历史仍是回溯诊断，不能称为新独立样本外。
- 12个固定Ridge模型：价格指标基线、技术／市场、宏观新闻、完整模型 ×1／4／24小时预测。标准化、缺值填充、因子选向与8因子组合仅使用训练期；标签在训练边界前成熟，评价窗口尾部未成熟标签不评分。
- 56个基础账户：7窗×4组合×2档成本。另在事前指定的2025Q2做8个大资金账户，合计64。行情准备、全部因子、12次训练与64账户约 **81.8秒**，无需长日历等待。

完整模型在4/7窗净盈利，在5/7窗高于技术／市场模型，但这不足以证明宏观新闻有稳定增益：组合路径、风险退出及已看过历史均会影响比较。完整模型在2025Q2五分钟观察回撤约15.14%，做多对照约17.10%，说明15%观察触发线不是实际亏损保证。完整窗口／成本／资金的指标以及预测MSE、MAE、IC／RankIC、ICIR、方向准确率、AUC详见 [summary.json](summary.json)。

历史多空预测与短窗口均有不确定性。预测指标和成本账户结果分开，统计相关不当作账户盈利；没有以单个盈利窗口改选候选或建立实盘资格。

## 现有界面与复跑

在 CZ-Agent 原有 `web/cockpit` 中新增“因子与组合”入口，路由仍为 `/research#factor-lab`。能够筛选因子类别与适用市场、输入正负权重、切换固定模型或自定义组合、调整本金／成本／调仓／敞口／止损、运行真实研究账户，显示净值、回撤和成交容量。另有预测检验、官方新闻和市场常用指标三个页签。

市场常用口径包括净收益／CAGR／波动率、Sharpe／Sortino／Calmar、回撤与恢复期、PF／胜率／盈亏比／每笔期望、费用／滑点／资金费、换手／敞口、相对BTC价格基准的Beta／Alpha／信息比率／跟踪误差、日VaR／CVaR。风险比率基于UTC日净值、365日年化、零无风险利率；短窗口年化仅是描述，未定义值显示为空。BTC价格基准不含交易成本与资金费，不冒充可交易基准账户。

```sh
# 在TradingAgents根目录，使用现有独立研究解释器，新目录不可覆盖。
PYTHONPATH=. ../freqtrade/.venv/bin/python -m research_tools.factor_lab study \
  --run results/research/factor_lab_<new_version>

# 独立审计。
PYTHONPATH=. ../freqtrade/.venv/bin/python -m research_tools.factor_lab_audit \
  --run results/research/factor_lab_<new_version> \
  --output results/research/factor_lab_<new_version>_audit

# CZ-Agent根目录启动现有工程的研究服务。
python3 web/cockpit/scripts/research_server.py --port 8793
```

实际运行时替换占位名称；服务可通过 `COCKPIT_FACTOR_LAB_ROOT` 指定新实验。数据输入仍依赖已封存的公开行情缓存，来源路径／摘要在 [registered_plan.json](registered_plan.json)。源码变更后，旧实验的交互重算会拒绝；应登记新版本，不追溯重写旧收据。

每次界面运行均创建独立研究账户与配置，不读取交易凭据，不导入生产引擎，不产生真实订单。查看留出结果后调整组合会消耗该段留出用途，必须保留探索身份。

## 验证与限制

独立审计重建64账户的现金、资金费、成交量参与率、库存、每五分钟净值与主要指标；用独立特征分解重建12组Ridge系数与预测；从两个真实截断输入重算全部74因子，前缀一致。股票日历、新闻可用时间、未来量只影响成交、风险退出持续与输入拒绝亦有专门检查。新旧研究回归共182项通过。

浏览器已验证现有研究页入口、单因子选取与调权后真实POST计算、预测页、新闻来源、常用指标和手机布局。无相关控制台错误或页面溢出。原v001阶段的时区切片错误、目录迁移、非经济浮点预算dust与对照预测语义修正均保留旧版本；没有靠改参数挑选更好的收益。

本轮仍是模型约束的历史研究。固定当代六币池有选择偏差；历史交易精度、最小金额、盘口冲击、真实保护单和精确资金费结算价尚未证明。没有推送、部署或接入实盘，未确认稳定有效收益源。
