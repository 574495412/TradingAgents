## 核查现有目标后发现的问题

原目标已要求扣费、历史可得信息、闭合周期、容量、连续账本和恢复验证；但仍有六个不足，完整记录见 [objective-audit.json](objective-audit.json)。

1. 外部独立核对没有成为硬门槛，内部回测和测试可能被当成充分证据。
2. 30/100周期只是最低计数，不能代替独立样本、统计功效、多重选择校正。
3. 16期ARK披露属于窄历史队列，不能当作全市场证券主表；EXAS仍缺64个交易日行情和并购现金可用时间。
4. 日低价包络与日成交量参与率无法认证同步盘中回撤、竞价成交或目标资金容量。
5. 当前个股机制回撤超限、样本少，所查加密研究缺乏合格模块。本轮采用的2025—2026加密账户与股票不同期；另有旧2024训练的日历重叠，但账本/执行/范围不兼容，尚无可直接采用的同期组合净收益。
6. 目前没有外部独立重建、签署差异报告或本目标的真实前向账户证据。我们的Decimal复算和新进程恢复属于内部工程核查。

此前结果原样保留：[个股研究报告](../equities_pit_stocks_20261026/README.md)。高成本个股动量净年化6.80%、回撤28.99%，只有8个闭合周期；这不是可以通过提高样本计数或调整目标标签解决的问题。

## 专家会补做的研究

这些是本项目采用的专业研究要求，并不声称所有专家采用完全相同的流程。

- **解释谁在支付收益。** 分清市场/行业暴露、选择效应、流动性补偿、真实资金费与不可复制的收入；明确竞争、费用、制度变化及哪些观测会否定机制。
- **把“当时能知道什么”做成可复算对象。** 区分证券和发行人、会计期和披露期、业务生效时间和获知时间；保留退出证券、修订、错报和付款延迟。
- **主动寻找反证。** 同机会集、同风险对照，固定消融与安慰剂，检查是否被个别股票、时期或风险暴露支撑。敏感性结果不得用于删除亏损样本或重选赢家。
- **检查研究本身造成的偏差。** 登记所有影响选择的尝试、有效样本与试验相关性，设定最小经济优势和功效要求。已看历史不重新包装成独立样本外。
- **从收益公式追到实际资金。** 验证次开盘能否成交、部分成交/拒单、结算和保证金、错腿、退出成本、停机及跨年高水位。
- **让独立者有能力推翻我们。** 外部参与者获得原始数据出处和冻结规则，独立实现、盲算并列明差异；真实前向成绩另外核对外部账户凭证。

**G7不能由我们自己的测试、同一引擎再次运行、另一个AI表示赞同或一份本地哈希代替。** 独立审计人需要具备合法数据访问和相关核查能力，不得参与选择过程或预先知道期望结果；实际独立性及凭证真实性还需要核实。若未取得，状态保持待验证。

G8的达标期要求总本金扣全部成本净CAGR≥50%、同步可执行口径最大回撤≤15%、净夏普≥1同时成立，且由独立者核对外部记录。100个周期只是既有最低计数；相关交易多、有效样本少或功效不足仍未通过。前向影子/模拟可以验证该模拟规则的表现，不能成为真实账户绩效证明。

这里区分三个结论：

1. **研究证据可信**：完整、可复核，负结论也可以成立。
2. **策略准入通过**：机制具有可执行净优势，风险/容量和独立核对均通过。
3. **收益挑战达成**：满足G6—G8的统一账户及前向真实绩效证据，同时达到50%/15%/夏普1。

不能从第一项跳到第三项。外部复核可以提高对特定输入、时期和口径下结果的信任，不能证明未来永远达到该收益和回撤目标。
