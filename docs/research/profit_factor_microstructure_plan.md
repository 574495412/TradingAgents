# 同期盘口与成交印记反证

2026-10-16。对应TradingAgents已封存的`trade_print_artifact_counterhypothesis_v1`建议。
本计划在新增观察器结果分析前冻结，原双向基差候选、45基点阈值、60分钟中位数、交易成本、容量、退出与统计规则不变。
它只检验盈利解释，不能产生新交易信号或生产权限。

独立观察器只读关联研究协议，订阅事前固定的全部220合约，不读或写模拟账户和带单员标签。
每条原文同时保存交易所事件时间E、交易时间T、实际接收时间、时钟核验状态与物理连接身份。
连接完成全部唯一订阅回应后才形成可配对区间；重连形成新区间，旧缺口不回填。
任一路连续四次不健康连接即停止；健康须订阅确认后至少持续60秒并实际收到两次主动PING对应的PONG。
时钟失败区间明确未知，后续时钟成功不能改写早先消息的状态。

最优盘口来自公开`@bookTicker`，聚合成交来自`@aggTrade`；固定公开端点，不使用交易凭证。
盘口不含RPI；聚合成交的q包含RPI成交、nq为排除RPI的普通数量。
聚合成交不含保险基金及ADL，因此其时间仅称“已观测聚合成交年龄代理”，不能冒充所有类型的最后成交时间。
接口依据：[公开盘口](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/ws-streams/public)、[聚合成交](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/ws-streams/market)。

对同一活动、同一账户、同一合约的已完成分钟端点，采用原研究实际收到的合约收盘P、指数I与此前60分钟中位基差m。
盘口中间价M=(bid+ask)/2，分别列出`P/I-1 = (M/I-1) + (P-M)/I`以及残差`P/I-1-m`。
跨端点变化另列m的变化，不能把滚动基线移动算成实际基差修复或账户盈利。

可配对消息必须在端点之前发生、实际决策之前收到，且订阅确认区间覆盖该决策。
接收时间减事件时间不得超过5秒，盘口交易时间距端点不得超过5秒；不使用事后REST查询补成信号时刻的盘口。
聚合成交价格还须等于该分钟收盘，才报告年龄代理；预定年龄分组为不超过5秒、5至60秒、超过60秒。
没有满足条件的消息即未知，不放宽时效、不插值，不把未观察到的成交解释为零成交。
观察器启动之前的活动不能回填，同步观察开始后也不自动证明全部成交已经覆盖。

后续逐活动对接须保留原规则所有已授权活动，分别报告成交、复核拒绝、过时报价、容量拒绝、断层与未知；基础与压力账户分别分析，不能拼接赢家。
代数拆分是归因描述，不等于因果实验、可成交利润、稳定性或上线资格。
正式两个连续三十日阶段及固定五日循环块统计规则没有因为模型建议改变。

原文用无损分段存储；另设只检验字节和哈希链的读取器，提供者坏JSON也可原样取证。
消费者仍须拒绝坏JSON和非法字段；字节完整不代表行情有效。这个新读取器不修改正在运行的旧版本模拟账户。
