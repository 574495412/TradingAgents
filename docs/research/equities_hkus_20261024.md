# 港美股研究接入与首轮账户结果

2026-10-24：已实现港美股独立研究路径并运行 108 个扣费现金账户。训练期筛查后，美股与港股均选择 cash；没有合格新策略，没有生产放行。后段账户全部保留为固定候选诊断，不能用后段盈利反选赢家。

## 数据与冻结设计

- 预热及输入区间：2018-01-01 至 2026-10-01（右开）。训练 2020—2022，验证 2023—2024，留出 2025-01-01 至 2026-10-01（右开）。另跑 2023 年起连续账户，跨年度不重置现金和持仓。
- 这只是事后划分的历史时间段，非全项目未见数据或真实前向。
- 美股为 SPY.US、QQQ.US，初始 10,000 USD，各使用一半初始资金袖套；港股为 2800.HK，初始 100,000 HKD。固定 ETF 篮子不是历史全市场选股。2828.HK 因历史股息资料不足，在任何收益计算前排除。
- SPY、QQQ 各 2198 根日线，2800.HK 为 2152 根。所有价格、成交量和事件须已知，重复、缺时钟和分拆事件均拒绝；不前向填价、不把缺股息填零。
- 美股价格和三只基金股息来自 Yahoo；港股原始 OHLCV 来自腾讯公开 `day` 行情。Yahoo 港股曾出现零量平价和缺价，不作成交输入。腾讯在三个已确认休市日的零量平价行也被明确排除。
- 日历来源 exchange_calendars 4.13.2。按港交所公告补入 2023-09-01、2023-09-08 全天休市及 2023-10-09 延迟开市。日历与行情保存 SHA-256，其他历史临时开市时刻仍非完整官方审计。
- 三个候选：20/60 日均线趋势、200 日趋势过滤 RSI2 恢复、旧版 `ema_trend_pullback_daily`。旧因子原字节快照独立放入结果包，不导入 CZ 或修改原因子配置。其原总长度判断以固定前 79 根无信号掩码规范为前缀一致。
- 美股每侧 5/10/20 bps、每笔最低 1 USD；港股每侧 10/20/40 bps、每笔最低 15 HKD。它们是含交易摩擦的成本代理，不是长桥真实费率报价；未证明盘口、容量或下单可用。
- 收盘信号只在下一交易日开盘成交；整数整手，2800.HK 每手 500 单位，单市场单币种，无借贷与做空。股票不收加密资金费。
- 股息按除息日记不可再投资的应收款，整个账户期间不把未知派息日资金放回可用现金。美股固定扣减 30% 是研究假设，不代表任何个人税率；港股扣减假设为 0。
- 期末未平仓继续按收盘估值；不因已知样本终点伪造收盘成交。胜率和利润因子仅使用完整闭合交易；买入持有未平仓时胜率为空。
- 最大回撤是每日各持仓低价估值相对先前收盘峰值的包络，不是同步盘口或完整盘中最大回撤；收盘回撤单列。夏普／索提诺使用 252 期、零无风险假设，不能与加密 365 期结果直接混用。

训练筛查固定要求：三个成本情景均净收益正、完整交易至少 20 笔、有限 PF 至少 1.1、日低价包络回撤不超过 20%；合格时选择最差成本收益最高者，否则 cash。选择先写入 `selection.json`，再计算其余时间段。没有用后段结果降低门槛。

## 为什么仍选 cash

美股趋势训练仅 14 笔，旧 EMA 仅 19 笔，均少于预设的 20 笔；趋势的训练回撤也超过限制。美股 RSI2 在每侧 20 bps 的训练净收益为 −2.06%、PF 0.853，未通过成本压力。港股三个候选训练只有 7—9 笔，趋势和旧 EMA 亏损，RSI2 的最高成本训练也亏损。不能因后来某个窗口赚钱，就追溯改变选择或称其稳定盈利。

## 复算与实现验证

独立 Decimal 账本重建覆盖 108 个报告、69213 个权益时点、2637 笔成交，逐项核对现金、原始开盘价、整手、最低费用、股息归属、期末持仓和浮亏包络；最大权益绝对差 9.017E-11 原币。复算不调用账户引擎，收据为 `independent-audit.json`。该审计证明账本算术一致，不能认证行情来源或交易可成交。

15 项针对性测试覆盖下一开盘、股息归属、不可再投资应收款、期末未平仓、含浮亏风险、真实休市／半日／DST、源缺失、重复和分拆拒绝、训练选择、源码冻结和前缀一致。旧股票因子还对三只实际标的做了 79/80/120/240 根及长前缀与未来扰动核对。CZ 的 21 项面板适配测试通过。

17 份原始、规范化和日历文件的 SHA-256 全部复核通过，收据为 `source-integrity-audit.json`。`legacy-factor-inventory.json` 记录旧股票库全部 10 个因子的周期、原字节哈希和历史未通过状态；本轮只评估已冻结的 EMA 日线一项，不把小时因子直接放进日线。

## 使用入口

独立研究环境安装：

```sh
python -m pip install -r tradingagents/research/equities/requirements.txt
python -m tradingagents.research.equities --help

# 新采集、实验目录必须不存在。
python -m tradingagents.research.equities capture --output data/research/新的港美股数据目录
python -m tradingagents.research.equities run \
  --dataset data/research/新的港美股数据目录 \
  --output results/research/新的港美股运行目录 \
  --legacy-factor ../CZ-Agent/factors/stock/code/ema_trend_pullback_daily.py
```

已封存原文和规范化输入位于 `data/research/equities_hkus_20261024_v006/`；前五次不完整采集保留为数据质量调查证据，没有作为账户数据使用。108 个结果和冻结源码位于 `results/research/equities_hkus_20261024_v001/`。只做复算时可直接复用封存数据，不能把重算称为新样本外。

长桥只读采集由调用者环境注入 `LONGPORT_APP_KEY`、`LONGPORT_APP_SECRET`、`LONGPORT_ACCESS_TOKEN`（兼容对应 `LONGBRIDGE_` 名称），不自动读取任何 `.env`：

```sh
python -m tradingagents.research.equities broker-capture \
  --start 2026-09-01 --end 2026-10-01 \
  --symbols SPY.US QQQ.US 2800.HK --output data/research/新的长桥行情目录
```

此命令只创建 QuoteContext。长桥 K 线输出不自带完整股息／分拆账本，不能给缺失事件造零或直接冒充现金账户输入；需补真实事件源并通过同样的日历与价格审计。当前可用环境和历史配置缺完整凭证，本轮没有成功鉴权收据；公开数据不能写成长桥已验证。

面板由 CZ-Agent `python3 web/cockpit/scripts/research_server.py --port 8790` 启动。市场选择位于首屏，显示原币，未标注报告保留未知，股息核验与生产资格均显示未通过。

## 原始依据

- [长桥历史 K 线](https://open.longbridge.com/docs/quote/pull/history-candlestick)：明确复权、日期查询、正常时段及 1000 根上限；适配器按 180 天请求原始日线。
- [长桥 Python SDK](https://longportapp.github.io/openapi/python/reference_all/)：仅使用 QuoteContext、Config 和只读行情。
- [yfinance 历史接口](https://ranaroussi.github.io/yfinance/reference/yfinance.price_history.html)：显式关闭自动复权、修复和盘前盘后，保留事件及缺值。
- [腾讯公开行情入口](https://web.ifzq.gtimg.cn/appstock/app/fqkline/get)：原始 `day` 响应按年度保存在数据目录，未改为 qfq/hfq；不是付费行情认证或精确成交来源。
- [盈富基金发行方资料](https://cms.hangsenginvestment.com/cms/ivp/hsvm/document/2800_kfs_e.pdf)：HKD 计价，每手 500 单位。该快照不替代完整历史证券规则库。
- [港交所 2023-09-01 休市](https://www.hkex.com.hk/News/Market-Communications/2023/2309012news?sc_lang=en)、[2023-09-08 休市](https://www.hkex.com.hk/News/Market-Communications/2023/2309083news?sc_lang=en)、[2023-10-09 延迟开市](https://www.hkex.com.hk/News/Market-Communications/2023/2310092news?sc_lang=en)。
