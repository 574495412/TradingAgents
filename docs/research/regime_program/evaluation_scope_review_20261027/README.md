# 公开盈利策略与本地评估口径核查

2026-10-27。**确认存在需要纠正的结论范围；本轮所测情形未发现基础现金计算错误。** GitHub有公开盈利回测，本地改造版本失败不能直接否定原策略；反过来，公开盈利也不自动满足本项目的资金和风险要求。本轮仅静态方法核查及合成控制，没有运行新市场策略。

## 本次确认的差异

1. **原方法与本地政策不同。** 已封存映射显示，原趋势研究用12个月方向、持有1个月；本地EMA32/128、日频、8%价格止损、15%永久账户停机是不同政策。既有后续月度试验亦有自己的适配与阴性结果；不能将任何一个本地变体称完整复现。
2. **永久停机限制了后续结论。** BTC可交易EMA压力账户在2025年7月停机，2026继承停机。2026零收益描述该账户状态，不能评价2026年的原始信号有效性。永久停机按原风险合同仍保留，不能为了收益追溯关闭；另行解释信号与风险层。
3. **盈利、原法复现与准入是不同主张。** [backtesting.py作者教程](https://kernc.github.io/backtesting.py/doc/examples/Quick%20Start%20User%20Guide.html)公布GOOG 2004—2013年SMA10/20结果：累计462.64%、CAGR22.44%、回撤33.93%、Sharpe0.60。是作者表格、尚未本地复现；虽为正收益，却未满足本项目15%回撤/Sharpe1。它不是当前加密盈利证据。
4. **完整仓位与配置影响可比性。** [NostalgiaForInfinity](https://github.com/iterativv/NostalgiaForInfinity)建议5分钟、40—80个稳定币交易对、6—12个并发仓位和动态资金，要求不覆盖其退出/周期配置。当前仅核对原README，未运行或验证其收益；不能用单币、改周期或另一套退出规则代称原版。

在市场评估引擎原件不变的条件下，事先登记21条可手算现金路径及1条冲击后恢复的停机路径。用固定40单位、100入场参考价、95/100/105退出参考价、5bps手续费及0/3/10bps不利滑点，分别检查多空盈利/亏损、平价费用和正资金费的收支。Decimal公式独立算闭合现金；成交价格已含滑点，不再次扣分列滑点，平仓后不遗留退出准备。

这只排除所测算术错误。它不验证原始市场输入、信号移植、真实成交价格、队列、真实客户费用，也不是GitHub策略复现或外部第三方验证。合成路径不得计入盈利账户、独立机会、因子样本或经济变体。
