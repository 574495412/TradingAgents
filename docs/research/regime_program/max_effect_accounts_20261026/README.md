## 失败机制与有潜力部分

- MAX2025高成本沿实际成交路径还原的扣费前、资金费前、滑点前价格PnL为−986.47USDT；加BTC对冲为−1165.76USDT。手续费27.17／28.40、滑点54.33／56.80USDT不足以解释全部亏损。这个会计分解不是关闭费用后的另一次回放，不能推断零费用也会保持相同停机路径。
- MAX2026高成本比同期限普通动量累计多24.78个百分点；但共同有仓82日的日收益相关约0.68，两个账户的实际敞口、停机和后续资金利用率不同，差值不等于隔离的纯因子增益，更不能据此认定两个独立机制。
- MAX2026未对冲／BTC对冲的有仓时库存估计beta绝对均值为0.1864／0.1530；日收益对BTC回归beta另为0.0072／−0.1240。对冲版仍有实际残余暴露且净收益−6.60%。估计目标中性、成交后库存估计暴露、未来实现收益beta是三类不同量。
- MAX2026高成本115个闭合周期的PF仅1.079；按币聚类的单周期期望95%区间约−13.29至20.94USDT，按入场月约−19.03至28.51USDT，均跨零。正点估计没有消除估计不确定性；这些区间也没有校正全部历史搜索。
- 周频只改变信号形成节奏，单币止损、部分成交和已确认退出仍会改变实际库存。不得为留住2026盈利而追溯关闭2025止损、重置高水位或按盈利状态补规则。

## 来源、因子与明确改编

[Ozdamar等，2021](https://link.springer.com/article/10.1186/s40854-021-00291-9)研究的是加密MAX正向延续：过去28日的最大单日简单收益、周频形成，高MAX做多／低MAX做空。本轮方向在账户收益前固定，没有套用股票MAX的负向方向。来源原523币现货、分位／市值权重与本轮40币永续、等权4多4空不同；不继承论文收益。

[Sila等，2025](https://link.springer.com/article/10.1186/s40854-025-00777-w)提供加密beta预测和对冲不稳定的反证参考。本轮60日同期BTC OLS只是固定工程对照，不是该论文的完整方法或MAX原文的领先／滞后市场回归。[Liu等共同风险因子](https://www.nber.org/papers/w25882)用于提醒市场／动量重叠；原始HTML已封存并校验，本次网页复核该NBER链接返回403，不宣称当前可公开抓取。

数学定义只有统一目录`factors/common/max_effect.py`一份：MAX28、普通28日累计动量、60日beta与滞后流动性／年龄资格。BTC从所有排序中排除；过去28日平均真实日成交额≥5000万USDT，≥180已观察日，按成交额取最多30币，至少10币。两种因子各4多4空，beta版追加BTC并只向下缩放至unit gross≤1；账户初始gross0.8，无杠杆上调。每日观测、特征全部延迟一个完整UTC日，周一00:00及冷启动形成。数学可共享；股票交易日历、MAX方向和成交规则未在此验证，原74列面板不变。

## 数据和账户证据

40币源是已封存的2023年8月起五分钟行情，币池按后来可见流动性选择，存在事后选池／幸存者偏差，不代表完整历史上市和退市横截面。新采集86个核心分页＋40次精确终点查询，共126次请求、78,745条真实资金费事件，保存原始毫秒`fundingTime`、实际`markPrice`和JSON；所有核心名义结算时点／费率与旧封存日历一致。2026-09-01 00:00:00.000Z精确边界40查询均无事件；不是把终点缺失自动补零。未使用小时开盘mark代理。

新Freqtrade`calendar_portfolio.py`版本只用于本轮，旧引擎和失败证据不改。每根五分钟先按已知现金提交请求，再按(clock,next5m]结算真实资金费，最后收盘撮合；进场同刻资金费归原库存。反向必须旧仓确认退出，下一根才能提交并成交；止损／停机取消挂起反向。1%真实五分钟成交额仅为容量代理，尚无盘口验证。包含手续费、滑点、资金费、退出费用准备、实际加减仓和未完成退出。

输入独立复算708个候选／区间／形成时点案例（包含重叠，不是708个独立日期），最大误差2.18e−14；真实未来价格／量扰动3断点通过。24账户逐事件独立现金、持仓、资金费完整性、净值与生命周期复算全部通过，最大净值差4.01e−11USDT。审计反例验证：即使重新签名账本，删除结算或取消原登记形成时点也会被拒绝。四个连续高成本账户带仓断点（无对冲8仓、对冲9仓）及两个MAX跨年断点共6次：首进程退出后新解释器读磁盘JSON，曲线、事件、请求、周期和最终状态精确一致；跨年断点真实停机／空仓被保留，不宣称跨年仍有仓。

`max_effect_inputs_20261026_v001`因混合布尔／浮点数组的有限值检查失败，保留原目录；仅将验证数组转为float后生成v002，没有更改信号规则。资金费核心v001与补精确终点v002也均保留。所有正式账户仅计算v001一次，源代码和protocol快照在收益前固定。

## 验收与下一步

这是一组已观察历史的研究诊断；24账户、测试或恢复成功都不证明盈利目标完成。两个MAX连续版本按v002模块规则为`no_net_edge_current_domain`；未取得不同于普通动量的独立经济来源，也没有本轮10万／100万容量证据。不能把未触发的容量测试解释为该市场容量为零，更不能要求每个策略全年都盈利。

本轮停止MAX方向／28日／60日beta阈值搜索。后续先补更早完整周期及point-in-time可交易池，按冻结规则检查2025失败与2026差异是否可复现；若提出条件策略，适用域、交易时点与失效条件必须在下一批评价前另行登记，不能依据本轮盈利分组事后路由。合格的不同收益机制不足前，事件／神经配置不继续叠复杂度；原HMM、线性、MLP对照保留。订单、部署、推送均未启用。
