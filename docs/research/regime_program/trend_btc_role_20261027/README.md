## 结论

**BTC资格不是挽救这个EMA实现的充分条件。** 允许BTC入场后，两档成本仍亏损并停机；压力成本相对BTC排除账户只改善25.1623USDT，相对同绝对权重多头反而少0.4622USDT。关闭“仅因排除BTC才失败”的具体解释，停止旧EMA资格/止损/窗口微调。不据此否定全部BTC趋势或原论文月度策略。

## 冻结的唯一资格变化

旧池为每周历史合格前30个非BTC合约。新池把BTC按相同资格和过去28日报价额排序参与竞争，仍取30名，未给BTC保留仓位。88个周更新点BTC均通过资格，因此每周原边际第30名会退出。改变的是资格及相应选择/配置反馈，不能把整个账户差额当作孤立BTC仓位PnL。

趋势继续使用同一EMA32/128、冻结2024归一化、16%名义风险预算、原强度阈值、前10仓、有效180连续日、周度成员/日度00UTC信号。多头对照仅将同一日目标权重取绝对值；每一时点的选股和意图总敞口精确相同，但实际成交、净暴露、停机和持有时长可能不同，不能称实现风险已匹配，也不是被动买入持有。

原BTC排除目标逐小时精确重建。NumPy独立复算BTC资格、EMA/波动与仓位，最大权重误差2.36e-15；两个同源日档解释目标完全相同，因此8个新来源/策略/成本情景仅计算4条新账户。原排除账户复用，不能加成独立样本。

## 方向增量与费用

压力成本中，BTC可交易趋势与同绝对权重多头净PnL为-1046.3548/-1045.8926USDT。相对方向对照的算术归因：价格组成（加回已付佣金和滑点、保留这条实际路径）改善137.6840，资金费改善7.0503，多付佣金与滑点145.1965，净差-0.4622。不是零费用账户重跑，也不能把滑点重复扣减。

趋势本身该价格组成仍为-764.7348USDT，不能仅靠降低本路径费用就解释为已有正价格收益源。费用变化本身会改变成交、止损和停机，真正零费用反事实不能从加回费用直接推断。

本轮608日中BTC非零意图262日，实际压力趋势仅6个BTC闭合周期，净PnL21.3331USDT；这既不是262个独立试验，也不是BTC独立策略已验证。总账户资格改善额并不等于BTC分项PnL。
