# 原资金费空头逐币现货对冲：数据可行性与退出边界

本阶段没有新增财务账户，收益、胜率、回撤、夏普和容量全部未知。上一轮54案的失败结果仍有效，20%基础/30%挑战的多策略目标继续未完成。这里验证的是实际现货来源和双市场边界，尚未证明对冲可盈利。

## 预登记与风险预算

先固定原funding7_raw每个锚点的四个空头名额，再采集现货。比较原名额配对现货与固定四腿成本门槛两个方案，缺现货的名额保留现金，不补选、不向其他名额加仓。沿用BTC/ETH旧试点0.5初始总敞口、25%现货与70%隔离永续钱包，不提高杠杆。1000BONK/1000PEPE/1000SHIB因单位不匹配事先排除，不猜别名。

现货至少28个连续完整正量日、日均成交额1000万USDT；资金费按实际事件加5分钟可用，固定压力四腿开平费率0.7%，成本覆盖缓冲1.25。未建立资产同一性和真实五分钟执行数据前，数据候选标记不能作为可交易名额。数学定义仍在统一目录factors/crypto/matched_spot_carry.py。

## 实际来源与独立核对

88个名称、1056个登记月份；744个官方ZIP校验通过，逐行独立重读22,547根真实日线。312个未观察到的归档月继续未知，不补零、不自动解释为退市。共1577次只读HTTP、约3.1MB来源响应，原始目录、ZIP、官方CHECKSUM及每月回执均封存。采集定义固定于binance-public-data的d571690eb66760763b0bd6e27e8cd35603c7e244版本；现货归档2025年前后毫秒/微秒单位分开处理。

最初6个月因真实交易日提前结束而被严格整日解析器拒绝，原v001与其审计保留。v002只从同一原始ZIP恢复这些月的完整日，将6个实际短日标为因子不可用；没有新请求、补价或改OHLC。独立Decimal/CSV审计核对全部744个月，包括6个短日。6次未来现货成交额/资格与资金费扰动不改变过去特征；这证明时序和算术，不证明收益。

## 极高资金费与临近退出

全部1416条名额记录包含重复来源和冷启动窗口，不能当1416个独立机会。跨年主来源实际352个周度名额中，167个仅通过数据及正资金费条件，49个不同名称；只有2个通过固定成本门槛，资产映射仍待全部完成。

这2个时点是2025-03-17的BNX（过去7日费率1.688658%）和2025-09-15的HIFI（1.771606%）。按已知永续/现货边界及退出规则，距离首腿退出只剩8.5小时和50.5小时。过去7日高费率不能按整周延续，也不是可收到的现金。持有期截短后能否覆盖开平成本仍需在账户计算前明确处理，不能为了保留高收益名额而忽略终止时点。
