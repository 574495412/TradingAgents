# 真实现货对冲数据已备齐首批，核心币资金费本身不能承担20%目标

2026-10-26。条件适用域10账户未发现双成本净优势后，核查独立的现货多头＋永续空头资金费机制。它与既有双永续协整币对、资金费＋动量排序不同。此轮只完成数据和成本算术，没有建立交易账户，收益、胜率、回撤、夏普与容量均未计算，多策略总目标仍未完成。

先在提交`36b328a`固定两币、日期、42归档/6资金费请求的预算与两档成本，再采集新现货数据。BTC、ETH作为两个流动性核心市场试点，未依据新资金费诊断排名。历史已查看，不能称新的独立样本外，也不代表40币覆盖或最优资金费组合。

## 可以建立真实双市场账户的数据基础

2024-12-01至2026-09-01左闭右开，639日。42个官方现货5分钟月归档全部核对官方SHA256；每币184,032根连续K线。独立程序用标准CSV解析器重读全部2,208,384个价量值，与Parquet完全一致，未补零或前填缺口。

公开只读Binance连接器共6页返回3,834条历史资金费结算，实际费率与原封存数据一致，并新增保存每笔实际`markPrice`和毫秒级`fundingTime`。结算时刻相对整点最多偏移26毫秒，不对齐成整点以抢先获得信息。以后信号只能使用已到达且完整可观察的记录。原生现货/永续API各2根K线与归档核对一致；API仍是毫秒，现货归档2025年起为微秒，两者分别解析。它不是数据到达延迟或实盘认证。

永续行情沿用已有封存文件和其官方归档链，核查文件哈希；没有把永续价格复制成现货。全区间同步成交收盘价基差中位数：BTC约−4.51bps，ETH约−4.54bps；极值分别约−51.35/+69.25bps和−70.25/+77.66bps。这只是逐5分钟成交收盘价格差的诊断，不是可成交价差、资金费、基差年化或最大保证金风险。

官方数据说明固定于[binance-public-data d571690](https://github.com/binance/binance-public-data/tree/d571690eb66760763b0bd6e27e8cd35603c7e244)，保存README与数据使用条款的原始字节和摘要。归档可能被官方修订，本地保存本次原始ZIP、CHECKSUM及完整清单。

## 资金费收入要先覆盖真实交易成本

以下只是逐笔资金费率之和。固定空头名义本金占账户40%时，相乘得到的算术贡献**不是执行收益**：没有处理标记名义额变化、基差损益、手续费、资金占用、保证金和成交过程。

|市场|区间|结算笔数|负费率笔数|费率累计|乘固定40%空头的算术贡献|
|---|---|---:|---:|---:|---:|
|BTC|2025全年|1,095|141|5.1264%|2.0506%|
|ETH|2025全年|1,095|177|4.9287%|1.9715%|
|BTC|2026年1—8月|729|208|1.7428%|0.6971%|
|ETH|2026年1—8月|729|239|1.0438%|0.4175%|

两行2025结果是分别把40%空头放在该币的示例，不能相加成同一0.8gross账户的收益。2026行是243日累计费率，不作为长期年化收益。2024年12月仅为数据热身，完整数字在summary.json。

现货佣金采用当前[Binance普通用户公开费率](https://www.binance.com/en/fee/trading)10bps/边，不假定BNB折扣；永续佣金沿用研究假设5bps/边。两者均不是本用户实际或历史每期手续费的认证。每腿每边滑点固定3或10bps，含开平四笔：

|情景|现货每边佣金＋滑点|永续每边佣金＋滑点|40%现货＋40%空头一轮成本占NAV|覆盖一轮所需空头费率累计|
|---|---:|---:|---:|---:|
|基础|13bps|8bps|0.168%|0.42%|
|压力|20bps|15bps|0.280%|0.70%|

这不是未来资金费预测，也没有假定每天固定三次结算。实际费率可能转负。只按40%固定空头赚资金费，达到20%NAV的算术收入需要年费率累计50%，而本试点2025两币约5%；不能靠把这两币简单常持资金费包装成20%净收益。其潜在用途是低换手分散模块，仍须真实账户验证，不能据此认定已经盈利或无风险。

## 下一项与仍缺的证据

先补齐保证金风险所需的连续标记价序列，再冻结有限双市场账户方案；必须分别记录现货现金/币库存、永续保证金/浮亏、可转移现金、真实双腿成交与失败对冲退出。用同一账户保留跨年库存、高水位与停机状态，包含全部费用和基差变化，独立重算并真实JSON恢复。现货升值不能直接当成永续可用现金；假定两腿经济对冲不能替代清算风险检验。

先比较固定对冲与成本约束的条件持有，再决定是否值得扩展事前流动性池；不因试点费率低就加杠杆、选事后高费率币或重刷参数。试点只有2币、无历史盘口/完整历史保证金档位，容量、保证金模型与交易所资格仍未认证。总账户20%/15%/夏普1目标保留，缺失实际值仍为空。
