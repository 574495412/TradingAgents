## 已落地的数学与未通过的数据契约

统一目录`factors/common/year52_momentum.py`实现来源日期标签分组、两周收益端点、外侧五分位市值权重、资本gross映射和严格输入门槛。51个七日标签组后，年末一组含8日，闰年9日；跨年两来源周可覆盖15/16自然日，不能机械用14日shift。日期标签不指定下单时间，必须另有实际可用时点。

来源的+1多头／−1空头价差是gross2；gross0.8账户需把相应权重乘0.4，再计算真实费用和资金占用。字典序同值处理、整数名次分位是已披露本地约定，尚无作者代码逐项一致认证。模块没有计算未来组合收益、按论文截尾实际账户损益或接入收益回放。股票不得直接继承该加密日历，需要独立交易日和公司行动适配。

市场数据以稳定供应商ID、原生链/合约身份、观察日期及当时可用时间为粒度。缺市值、未知身份/稳定币/包装币分类、重复资产、未满30观测日或未来才可知的记录不能进入组合；市值不得用今日值、成交额或等权代替。七项反例测试通过，其中未来版本不会改变过去权重，缺中间周不能伪装完整两周期。

本次公开历史探针请求2025-01-07BTC原记录，返回401/error10012：当前公开API历史范围限过去365日；不是市值为0，也不证明其他合法来源都不可得。官方[停用币列表说明](https://docs.coingecko.com/reference/coins-list)另外标注Analyst及以上权限。因此没有取得该原法所需的历史市值及完整身份面板。四份方法/官方文档正文与一次失败响应均原样封存，未读取密钥、付费或规避访问限制。

供应商历史市值本身是派生观测，不是链上原生事实；今日下载的历史快照也不自动认证当时版本。旧40币池仍有回溯选择和幸存者限制，不能因公式变化就声称已修复；已有历史原生币池研究也不能替代市值身份映射。
