## 已执行

- 复用此前固定的PST EWMAC、突破、mr_wings及Sentinel资金费／动量来源，补hmmlearn0.3.3（commit `67c5a95009afe95317923c9fbe75f47962037f48`）、scikit-learn1.7.2（`25dee604bae18205b01548348388baf7a1cdfe0e`）和方法文档，共13份代码／许可／文档回执。版本、许可、具体文件和SHA见 [来源清单](source_review.json)。没有执行下载的第三方交易程序。
- 对既有40币官方校验行情运行每日状态分类。2025年：震荡237天、上涨趋势59天、下跌趋势27天、波动扩张42天；2026年1—8月：148／19／19／57天。这是固定阈值分类分布，不是分类准确率或策略适配成功率。
- 对450、730、1000日三个真实数据截断点逐项检查，追加未来数据及修改当前日以后价格／成交额不改变已有决策。股票日历的测试保留观测交易日，不补周末。公式状态和五类特征统一置于 `factors/common/market_states.py`。
- 五类策略意图：趋势、相对动量、资金费＋动量、mr_wings极端回归、突破；现金、等权及规则／事件／HMM／线性／MLP配置形成12个输入。资金费＋动量与其去资金费版本属于一个家族的消融，不能凭名称算两个独立收益机制。mr_wings只在源公式的极端区间启动，未降低阈值凑交易。
- 20次月度拟合覆盖608个决策日。HMM只向前过滤；线性与单个固定16隐藏单元MLP均使用过去365日、至少180个已成熟样本。首个2025-01-01拟合最晚训练决策为2024-12-30，最晚标签可用时刻2024-12-31 00:05 UTC，严格早于拟合时间。
- 独立审计不导入hmmlearn、sklearn或模型模块，以归档的权重、标准化、转移矩阵和高斯参数重算全部608日：线性概率最大误差2.22e-16，MLP误差0，HMM状态全部一致。12个组合意图均为单位敞口内、最多10币；还需由执行账户乘0.8总风险预算及事件系数。
- 22份官方FOMC原文与公开时点哈希复核，通过发布后5分钟才允许覆盖；2024年起504个小时决策被标为发布后24小时窗口。该标志只表示已覆盖FOMC事件，不表示其余时刻没有新闻，不预先使用实际发布时间。

模型拟合保留336条NumPy2.5数组shape弃用警告，没有优化未收敛警告；警告与每次拟合参数均保留在本地 `fits.json`。环境通过两个临时依赖目录隔离，未修改交易应用环境。独立检查能证明时序、算术与输入边界，不能证明预测／收益增量。
