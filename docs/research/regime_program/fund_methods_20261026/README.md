# 基金方法研究与研发目标纠偏

核查日期：2026-10-26。用户纠正：不同环境应有不同策略，不能要求单策略覆盖全部行情。此前执行代码把总账户20%年化门槛用在每个策略的全年筛选，这是目标层级错误。历史实验保留原协议和原判定；从新版本起改为分层验收，不追溯修改失败记录或把已看过的行情重新称样本外。

## 新版目标的三个层级

1. **收益模块**：先登记经济机制、可观察的适用域／禁用域、持有周期、失效条件和成本假设。只在当时满足适用条件时允许交易，其他时段可以现金。检验相同机会集下的扣费优势、完整周期损益、尾部损失、成交和容量；不要求单模块全年年化20%，也不要求每个分组盈利。若样本不足则标为证据不足。
2. **配置与风险层**：比较同一批模块的静态分散、过去波动率风险分配、有限规则调权，再考虑HMM／MLP增量。共享本金、库存、风险与容量，计入净额化、交易冲突及切换成本。通过“移除某模块”的消融检查其贡献，不能把独立满仓回测收益简单相加。配置模型必须优于可执行的同风险基线，不能只优于某个故意选弱的策略。
3. **多策略总账户**：原20%扣费年化／15%回撤／夏普1保留为研究目标，挑战年化30%。它不是基金行业标准或可保证结果，也不决定每个模块是否有研究价值。至少两个有证据的不同机制；完整总账户两成本均验收。缺乏独立机制时可以保持现金并继续研究，不为达标加杠杆或拼接赢家。

所有层级共用因果数据、真实成本、连续高水位、可恢复状态与资金上限。适用域也须在评估前固定；不能看见某些盈利月份后给它们起一个行情名称，再把亏损月份归入禁用域。

## 统计与样本口径

模块研究初筛：在预登记可用域内，两成本均报告正负净期望、闭合PF、损益与尾部，而不按20%年化一刀切。正收益但少于30个完整匹配周期或少于4个币对／独立入场月簇时，保留“证据不足／研究候选”；不能自动进入正式组合。这里30和4是本项目最低研究门槛，不是统计充分性定理，区间仍须报告，也不把高度相关的币与月份当独立样本。净收益为负且无法定位可修复机制的方案停止同组网格。

组合验收仍要求至少100个完整周期、闭合PF至少1.15、扣费闭合PnL为正、10万USDT两成本容量表现、子模块贡献与风险相关性。风控覆盖层可减少损失而没有正的独立PnL，应按相同机会集下的总账户减损／收益代价验收，不能硬要求它成为alpha策略。

神经网络状态准确率、因子IC、独立回测收益均为中间证据。状态识别不确定时允许分散或降风险；是否只用单一策略、是否切换、是否常备多策略，都需要用同一账户扣费增量决定，不能预先假定全仓路由最好。

## 对正在运行研究的处理

币对26账户回放已经完成，财务核对全部通过。滚动方案高成本连续608日总收益+1.6393%，但只有5个匹配周期，10万容量高成本为-0.1408%；这组信息支持“样本与容量证据不足”，不应仅因未到全年20%就断言该机制在所有适用域无效。它也不能因此被宣称为有效收益源。形成期只是过去协整条件，并未预登记“仅在BTC震荡时启用”，因此不能事后筛选其中盈利行情给旧结果翻案。

旧v001筛选判定保留。新适用域实验要在计算新结果前另行登记，且复用已查看历史时明确标探索。旧代表单策略指标不再放进新版总组合目标的实际栏；新版组合尚未计算，实际值保持未知。

## 接下来按顺序推进

1. 为现有趋势、相对动量、资金费、价差回归、突破，以及事件风险层分别形成策略说明卡；区分基础价量、宏观风险和加密特有结构，不把所有条件压成一个BTC牛熊标签。
2. 先做可观察趋势／震荡／波动／流动性条件下的模块对照，固定禁用域、冷却和失效规则；保留全时段基线，防止事后挑环境。
3. 对有足够证据的不同机制，冻结静态分散、风险分配与有限调权三个组合基线，统一账户执行。模块不足时不凑组合数量。
4. 再验证事件和神经网络的账户增量。股票公司基本面／估值、借券和交易日历另走TradingAgents股票账户，不能用加密结果代替。
