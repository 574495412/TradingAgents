首轮只跑前5个模块各2档成本，最多10个新的2025筛选账户；沿用原公式、幅度、归一化和账户风险，不重训模型。策略卡中的状态由过去完整日已知，禁用域请求现金；旧库存仍按真实成本和容量退出，不直接抹掉。至多3个研究后续在看新诊断结果前冻结；预算最多46个新账户，已有对照尽量引用。后续身份和门槛详见封存plan.json。

模块代码 `research_tools/regime_program/module_gate.py` 已将总账户年化门槛移除：有正净收益但不足30个完整周期或不足4个分组，标证据不足；空机会集也不是经济失败。资金、时间窗、成本不匹配或未过财务审计的资料不能准入；仍须遵守事前风险限额和拟分配袖套的容量。通过模块研究筛选只表示可以进入组合实验，不等于总账户达标或生产资格。

旧币对结果在原始形成域的v002解释见 module_gate_assessment.json：滚动方案样本不足，固定方案在既定形成规则下无净优势。没有应用新策略卡的低趋势过滤，也没有重算／修改旧损益。每个模块的10万单独账户容量不等于总账户10万容量；必须结合实际分配资金袖套，在共同成交与风险约束下另验。

这些假设已经参考看过的历史，属于探索预登记。登记只能证明早于下一轮计算，不能把2025/2026重新称为未见样本外。不能根据这次模块失败再反复改变适用域、参数或行情定义。
