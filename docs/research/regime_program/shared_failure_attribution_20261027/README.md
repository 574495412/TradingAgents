# 共同亏损归因：市场暴露与固定路径剩余损益

本轮唯一问题：既有亏损是否主要只是共同BTC价格暴露，还是在明确参照下仍保留负向剩余？证据等级为条件历史模拟与内部核算。这是**已知结果后的解释诊断**，没有新策略、账户或经济变体，不冒充事前收益试验。

## 判定如何改变下一步

12条路径的固定参考价分量全负；单位入场金额BTC参照调整后12条仍负。用所用历史版本中每次入场提交前的60日beta参照，两份来源各有3条费用前价格残差转正；因此不能把全部亏损笼统称为所有信号完全无信息；3个正残差同样不能证明信号有效，系数误差和基准错配仍可解释。

不过将原路径模型手续费、成交滑点及报告资金费保留后，减去beta参照的诊断净差额有11/12为负。唯一正值是普通7日反转低成本路径+61.73USDT，同政策压力成本为−179.04USDT；六种政策均没有两成本共同正值。**没有证据把简单减费或BTC风险抵消直接升级为可投资收益源。** 原经济拒绝均保留，不登记只保留低成本赢家的对冲策略。

## 从哪些原件算出来

保留既有172名历史机会集，读取原四项政策8条连续账户及MAX7/普通7日反转4条，共12条、均含两个成本。读取封存模拟成交事件/报告资金费账本、持仓周期、五分钟净值、执行参考行情、BTC行情和两种已保留日档；没有新行情请求，没有按收益筛来源或币种。12条共享市场和代码、重复成本与两种beta来源，不算12个独立收益源或独立试验。

每5分钟按`参考价格损益增量 = 净值增量 − 资金费现金 + 手续费 + 模型成交滑点 + 退出费用准备变化`还原，再从原始入/退出参考价和实际数量独立重建每个周期的参考成本。两条路径最大误差3.14912540489e-11USDT，未放宽1e-6核算容差。该算术加回不等于零费用重新执行策略。

在实际入场收盘，以原币数量×参考价换算BTC单位，按实际增仓/部分退出同步持有和退出；没有赚取入场前的BTC变化。第二参照乘以提交当时仅使用前60日的OLS beta，保留首日/缺日及身份分段；不使用整段事后拟合beta、不补0或1。两种日线来源分别计算，实际入场均有完整beta，本次残差恰好相同，原来源差异仍保留。日档、公告仍采用已声明的历史可用时点假设，完整原始历史版本未认证。BTC不代表所有加密风险，对照不匹配可能改变解释；本轮没有因果识别或风险匹配的投资组合实验。

## 时间与样本限制

11/12路径最差的经济净值周落在2025-W03（1月13日至19日）；普通28日动量低成本路径最差周在2025-W07。这里按每根真实净值变化归周，未把最终平仓日当作全部亏损发生日。同期集中不证明是哪条新闻或哪类投资者造成，也不能据此事后屏蔽该周。

完整608日和停机后零区间保留；另列共同有仓日相关性与样本数，美元风险大小未匹配，只作描述。所有历史均已观察，归因不能变成新样本外，也未校正全部历史搜索。

## 验收和后续边界

5项反例测试检查入/退场时序、增仓与部分退出、缺失beta持续未知、准备金变化和未闭合拒绝。核算与参照是内部证据；没有第三方评审、实际对冲、容量或实盘认证。

停止把现有价格排序的方向/窗口试错当成新收益机制。若研究风险中性政策，必须重新给出完整资金/成本/库存/停机合同和可反驳的实用效应，不能直接使用本表减亏数；若研究新收益源，应引入新的原始信息或有证据支持的风险溢价机制。原有各分支的失败和未知保持不变。多策略总账户、两个合格独立机制及外部/未见验证仍未完成，总目标实际值为空。
