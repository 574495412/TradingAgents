## 执行顺序与验收

1. **对齐原版收益口径。** 作者报告数字逐字段匹配；每笔成交、双边费用、资金费、库存和末期结算能解释。没有原始导出就标明只能核对摘要。
2. **优先搜索高收益原件。** 固定来源、版本、许可证、资本、周期、币池、仓位、复利、杠杆、成本及数据；披露收益仅作取证顺序，不把stars、passed标签或截图当净收益证明。
3. **先按原版复现。** 不先加本地风险规则、不先改信号或调参数。数据/引擎/配置缺失不得用近似结果冒充完全复现；保留失败与未知。
4. **再比较、再优化。** 同可比条件按扣费账户收益排序，同时展示回撤、胜率、夏普、容量和分段结果。原版冻结、领先者明确、优化目标登记后，才逐项优化。

现有年化20%／挑战30%、回撤15%、夏普1及资本/容量数字保留作后续组合研发参照，当前不作为公开原版复现或来源筛选门槛。风险预算本身继续允许检验。未见、外部复核、长期经济有效性与真实执行另验；原版复现不等于实盘盈利。
