## 重写后的目标

> 在既有三项目与统一factors目录内，每轮只判定一个收益机制是否值得在明确行情和资金约束下投入资本。以流动性充足币种的中低频趋势／动量为起点，优先查原始论文、源码与基金披露，再核对本地偏离；已有反证和已看历史完整保留。结果评估前登记经济假设、最强替代解释、适用／禁用域、必要原始记录及其可用时点、唯一规则变体、完整成交与现金合同、简单对照、最小有用净效应、证据充分性和有限补证预算。从原始记录重建连续扣费账户，报告净收益、完整周期胜率、回撤、夏普、资本占用、容量边界及分时段表现，区分市场暴露、尾部风险补偿和可执行增量。用未参与开发者复算、规则冻结后的真正未见结果及另获授权后的原始成交账单分别检验实现、泛化与已发生经济收益；缺失层级保持未完成。每轮交付支持、反驳或未知的机制判定和继续、终止或封存决定。至少两个不同机制各自取得准入证据后，才检验共享资金、切换成本与共同容量下的组合；总账户仍以原本金和风险预算验证扣费年化20%／挑战30%、最大回撤15%、夏普至少1，不能靠扩大搜索、事后路由、拼接短窗或加杠杆达标。

## 1. 按顶尖研究团队的标准，主动补做什么

以下是本项目采用的研究要求，不声称每位专家或基金都采用同一流程。

- **先解释经济优势，再挑战解释。** 谁可能支付、为什么没有被竞争消除、资本承担什么风险？收益是否只是市场上涨、现金比例更高、集中押中少数资产，或卖出尾部保险？支付者动机没有直接证据时只是假说。
- **写出会放弃的条件。** 看结果前确定相对基线的最小有用扣费增量、统计判据、盈亏平衡成本、资本与退出边界；失败后保留结果，不通过换方向、换窗口、删年份恢复阳性。
- **检查数据如何形成及交易如何兑现。** 纳入历史退市与更名，分开发生、发布、接收和修订时点；追踪实际库存、失败腿、抵押币风险、保证金、残仓、交割及现金换汇。当前规则不能补成历史规则。
- **审查搜索本身。** 记录人工和自动尝试、已看过的区间及全部阴性结果；事后漂亮的最佳曲线需解释选择偏差。方法依据见[DSR原论文](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)，校正不等于盈利认证。
- **让反对者检查。** 提供能从零复算的材料和具体异议问题。基金披露、论文与GitHub业绩只提供机制线索，本地必须另验。

## 2. 从哪些原始记录开始

每项输入都须对应一个当前决策问题；只采所需粒度和范围，不要求建立全市场全事件仓库。

| 判断 | 优先原始记录 | 必须保留的字段与限制 |
| --- | --- | --- |
| 价格规律是否存在 | 交易所原始逐笔／成交ID、原始K线及归档校验文件 | 标的身份、事件时间、时间单位、原文件；K线足以初筛，不能证明队列成交 |
| 当时是否有资格交易 | 上线、退市、更名、换币原公告及历史规格；乘数、最小量、精度、状态、保证金 | 生效与发布／修订时点；当前名单和同名代码不回填历史 |
| 能否获得净现金 | 必要交易窗口的买卖报价、盘口快照／增量／序列；资金费、标记／指数、交割及收费规则 | 首次接收时间、完整失败及缺口；mark不代替可成交bid／ask，收费档位不是客户到账证明 |
| 事件是否能用于决策 | 央行、公司和交易所首发全文、附件及修订版本 | 预告、实际发布、首次接收时点；新闻摘要或事后情绪分数不替代原文 |
| 股票如何复用 | 未复权价量、上市／退市、成份变更、公司行动、SEC／HKEX原始申报与附件 | 申报受理、修订、股息／整手／停牌及USD／HKD现金；由独立股票任务执行 |
| 收益是否真实发生 | 另获账户数据授权后的委托回报、成交、收费、资金费、余额与划转原件 | 从委托到现金逐笔对账；没有取得就不宣称实盘收益 |

具体入口已核对[Binance官方原始归档说明](https://github.com/binance/binance-public-data)和[SEC申报接口说明](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)。聚合接口用作索引，重要历史事实回到原件。所有必要记录带来源、版本、身份、币种与可用时点；原始缺口不补零，派生数据能重建。

## 4. 除了我们，什么证据能检验结论

| 要检验的主张 | 外部证据／复核者 | 结论上限 |
| --- | --- | --- |
| 输入事实可信 | 数据持有方原始凭证；必要时独立来源复核同一事实 | 同交易所双接口只是同源对照；哈希只证明文件没变 |
| 计算与实现可复现 | 未参与开发的合格研究者，在独立环境从零复算并提交差异与异议 | 需原始记录、许可、身份／时点字典、冻结代码／依赖、全试验台账、运行命令、预期账本及事前容差；内部第二实现不算第三方 |
| 优势能在样本外延续 | 规则冻结后真正未访问历史或新产生的前向记录，留存事前信号、可见报价及全部失败 | 已看历史重新切分不是新证据；纸面成交仍受模型限制 |
| 经济收益已发生 | 明确获实盘授权后，交易所／券商原始成交与账单，由独立方核对现金、费用和权益 | 只验证已发生结果；过去实盘也不能证明未来持续盈利 |

**没有一个人、一个夏普值或一次审计能证明未来必然盈利。** 不同证据只检验对应主张。当前外部复现和真正未见验证未完成；本轮没有新增外部联系、账户读取或实盘操作。

## 一轮怎么结束，什么才算完成

评估经济结果前，登记最小有用增量的数值及单位、区间水平／方法、依赖／搜索处理，以及支持、反驳和未知判据。区间支持有用效应且必要经济条件通过，才在限定适用域内支持；区间排除有用效应或违反事前必要条件则反驳；区间跨界、样本依赖不明或关键事实缺失则未知。不能把“未显著”自动写成无效，也不能把少量正收益直接写成有效。

每轮只交付一份机制判定：**唯一问题 → 事前规则 → 决定性原始证据／反例 → 完整扣费效应与区间 → 失效边界／独立证据缺口 → 继续、终止或封存。** 缺证据须指定一个决定性缺口、合法来源、访问／计算次数上限；用尽即封存，待具体新证据重开。记录哪项资本决策因证据改变，来源数、测试数和模型数只记工作量。

分支结题可以是反驳或未知；盈利目标仍按原阈值单独验收。新目标只约束后续试验，不把已观察结果补称预登记。现有资金、风险及最低样本门槛保持不变：总账户1万USDT、gross上限0.8、两档完整成本、连续至少365日；年化基础20%／挑战30%、最大回撤15%、夏普至少1，10万USDT共同容量另验。完整周期胜率附区间和盈亏比，不以50%作统一门槛；最低周期数不是充分证据。

所有比较列出同口径净收益、完整周期胜率、回撤、夏普、成本／资金费、资本占用、容量与各自然年／90日块／事前行情表现；不完整时段和零闭合周期保留未知。各模块按自己的适用域验收，至少两个不同收益机制合格后才比较共享资金组合、静态分散与现金，扣足切换成本。不得要求每个子策略都达到总账户20%或每个时段盈利。
