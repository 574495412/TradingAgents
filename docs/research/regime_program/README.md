## 目标与计算口径

第三轮[协整币对形成期](pair_formation_20261026/README.md)已完成：固定7份来源记录，21次形成期共9250个双向检验，固定方案1对、滚动20个月仅5个月有入选，其余现金。全部p/q与22次Johansen数值独立复核通过，3个真实数据因果截断通过。这里只完成形成期，币对账户收益、胜率、回撤、夏普、容量均未计算；下一项是双腿独立成交、失败对冲退出、完整配对生命周期与恢复审计，再做最多26个成本／容量账户。R07/R08及总盈利目标保持进行中。

|指标|基础目标|挑战目标|验收范围|
|---|---:|---:|---|
|连续账户扣费CAGR|≥20%|≥30%|1万USDT、至少365自然日；8和15bps单边成本均通过|
|最大观察回撤|≤15%|≤15%|完整5分钟净值，含浮亏、资金费及退出准备；延迟成交超限仍失败|
|日净值夏普|≥1.0|≥1.5|UTC日收益，365日年化，无风险0；股票另用252|

主要指标固定为这三项。基础目标全部通过才进入收益达标候选；挑战收益不允许提高风险上限。CAGR按 `(期末权益/期初本金)^(365/自然日)-1`，不拼接冷启动窗口，不把28天均值当长期年化。已有2025/2026历史都已经查看，后续重用只能称历史诊断，不能重新标为未见样本外。

配套经济条件：完整生命周期至少100笔、扣费闭合PnL为正、闭合PF≥1.15；单个收益源至少30个完整生命周期。胜率必须报告净胜率、Wilson区间和盈亏比，不统一要求超过50%：趋势策略可以低胜率、高盈亏比，不能为刷胜率提前止盈或藏匿未平亏损。相关币种、同月成交不是独立证据，另报按币和时间块聚类的不确定性。

目标锚点来自已有失败证据，而非公开项目宣传：Sentinel历史21日资金费＋动量排序在15bps下2025盈利12.93%，2026年1—8月亏损7.76%，跨年608天总收益仅4.96%，并非年化4.96%。本计划要求改善连续与压力表现，不能挑2025单年宣布成功。完整依据见 [46账户报告](../github_factor_study_20261025/README.md)。

## 行情与策略研究矩阵

|当时可识别的环境|优先研究策略|首要反证与保护|
|---|---|---|
|上涨趋势|中低频多头趋势、横截面相对动量|是否只是BTC上涨Beta；与真实扣费做多账户比较|
|下跌趋势|双向趋势、相对多空组合|资金费、做空成交和两腿不平衡；无优势时空仓|
|低趋势震荡|价格／价差回归|换手后收益是否消失；拒绝事后区间标注|
|波动扩张|突破、加速|假突破与成本跳升；按波动缩小仓位|
|事件冲击|事件风险覆盖层|发布时间、预告与首次可用时刻分开存证；对比覆盖层的收益代价与减损|
|流动性不足／不确定|减少敞口或现金|不能将缺数据当零风险，不能强行选一个策略|

行情是决策时的信息状态，不是事后“牛熊标签”。先实施透明规则基线，再对比HMM统计状态模型与一个固定小型MLP；HMM不是神经网络。神经网络先检验状态识别／配置增量，预测准确率提高不能代替账户净收益。TCN、LSTM、TFT只在小模型确有增量后排队，避免直接投入大模型搜索。

至少两个不同经济机制在各自适用条件下有扣费优势才算策略多样性；同一趋势的多个参数不算多个独立收益源，现金也不算alpha。事件覆盖层是风险机制，不能因减少交易而声称新增收益源。各状态可能亏损；要披露收益、交易数、时间占比、暴露和最大损失，样本不足记未知，不要求每个小分组盈利。

## 一轮研究的预算与验收

先网络检索，后固定版本复现；只有发现具体缺陷、失效环境或数据差异后才自研。每个假说先写经济机制、适用环境、反证条件、输入可用性、退出规则与实验预算。来源没有可复现公式或明确许可时保留为参考，不直接搬运源码。文献／仓库收益与本地收益分列。

第一轮最多60账户：12个方案／对照在2025筛选×2成本共24；按2025两档成本较低收益冻结3个研究后续，再加现金、最佳静态、等权3个对照，在2026年1—8月及跨年608天×2成本共24；3个后续在跨年10万／100万本金×2成本共12。若机制不足，少做，不用调参变体凑数。具体12个版本及训练区间必须先登记后计算；筛选时的最佳静态只能由更早训练确定，后续比较的最佳静态由2025筛选冻结。后续名单是研究名单，未通过经济门槛仍不能准入。

组合必须与冻结最佳静态和等权组合比较。相对两者中较强的基准，至少实现以下一种增量：CAGR提高5个百分点且回撤不增加；或回撤相对降低20%且CAGR不下降。都在同一资金、可用信息、执行与风险预算下计算。每个方案直接回放一条连续账户，不能拼接独立赢家净值，不能跨年清空回撤高水位，不能将单策略停机后另开账户的收益作为恢复。

容量先验证1万、10万、100万USDT，10万为第一容量目标：两档成本净收益为正且回撤≤15%；100万为探索目标。报告成交／请求、退出延迟、实际净敞口、部分成交和订单TTL。当前成交额1%是研究代理，缺盘口证据仍标未知，不能称交易所已验证容量。基准gross固定0.8，不用增加杠杆实现收益门槛。

无强制最低研发天数，沿用用户此前取消固定30／60天前向等待的指令。真实前向可补证，不能冒充已有；新的历史留出也必须有预登记和来源访问边界。没有通过收益、执行、账本与连续性条件时保持未完成；生产接入、部署和订单仍是独立授权行为。
