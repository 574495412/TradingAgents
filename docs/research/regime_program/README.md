> 基于现有 TradingAgents、Freqtrade、CZ-Agent，从原始数据和可证伪的经济机制出发，一次做透一个收益假设：解释收益由谁支付、为何持续、何时失效；重建决策时可知的信息，验证真实执行约束、完整现金流和统计可靠性；形成未参与开发的人可独立复算、未见数据可反驳的证据。先验证不同环境下有效的净收益源，再研究其配置增量。最终多策略连续总账户仍以扣费年化20%、最大回撤不超过15%、日夏普至少1为基础目标，30%年化为挑战目标；禁止靠杠杆放大、扩大搜索或拼接短窗达成。未证实的收益、容量、前向和实盘层级分别保持未完成。

## 1. 专业研究流程应主动补做的事

- **先解释钱从哪里来。** 写清支付者、风险补偿/行为偏差/结构约束、竞争为何尚未消除优势、资本占用与失效条件。零假设是“扣费后无可利用优势”，不能从高回测收益倒推解释。
- **先反驳已有结论。** 原固定池与时点池、价格腿与资金费、身份与执行变化逐项控制。单变量消融保持其余条件一致；损益分解是描述，不自动证明因果。BNX/HIFI两个案例只检验退出与持有期假设，不代表全策略样本。
- **核算整个研究的选择偏差。** 记录尝试过的经济假设、参数、种子、数据版本、已访问区间和失败；重复控制、来源情景、冷启动窗口不能当独立发现，初始化失败也不是经济试验。
- **按实际交易约束判断优势。** 逐笔核对价格、资金费、基差、手续费、钱包、部分成交、强制退出和尾部损失，辨认平均收益是否主要补偿退市、流动性或保证金风险。
- **事先规定停止与复核。** 先确定什么证据会推翻假设，再运行实验；反证成立则停止分支，样本不足则记未知。不能用增加因子、模型、市场或数据量代替解决关键不确定性。

AQR的[原始交易成本研究](https://www.aqr.com/insights/research/working-paper/trading-costs)使用真实成交研究成本与冲击。我们借鉴取证方法，其股票样本数值不作为加密交易成本认证。

## 2. 从哪些原始数据入手

| 要回答的问题 | 原始记录 | 必须保留的边界 |
| --- | --- | --- |
| 信号价格能否成交，容量是否存在 | 交易所逐笔成交及ID、必要成交窗口的买卖报价、盘口快照/增量与序列；交易所时间、本地接收时间；原始ZIP/CSV及校验文件 | 只补会改变当前判断的时间窗；五分钟K线不能重建真实队列，也不能认证盘口容量 |
| 是否同资产，资金费是否可赚到 | 原始上线/换币/退市公告及可取得的历史版本；合约乘数、交易状态、精度、最小数量和保证金档位；实际资金费事件及标记价 | 同名代码不等于同资产；今天的公告正文不等于当时版本；公开费率不等于客户实际到账 |
| 账户现金与风险是否真实 | 已获授权账户的原始委托回报、成交、佣金、资金费收入、划转、余额与权益流水 | 不自动读取凭证或开展实盘；缺失流水就不能宣称完成真实现金对账 |
| 事件是否当时已知 | 央行/交易所/公司原文、原始新闻首发与修订、预告/发布/首次接收时间 | 整理后的事件标签或情绪分数仅是派生输入，不能替代首发事实与时点 |
| 股票如何复用此标准 | 历史成份与退市、原始未复权价量、股息/拆并股/整手/停牌公告、SEC/HKEX原始申报和受理/修订时间 | 股票研发由独立港美股任务执行，不修改其目标；不能用现时股票池或最新财报回填历史 |

原始响应不可覆盖，派生表可重新生成。记录来源、原始文件哈希、资产身份、时间单位、时区、币种及可用时点。哈希只说明文件未变，不说明经济事实一定正确；同一交易所的归档与API对照也不等于两个独立来源。

## 4. 谁、什么证据能独立检验结果

| 证据层 | 我们之外的验证依据 | 只能证明到哪里 |
| --- | --- | --- |
| 原始事实 | 数据持有方的原始序列/时间记录与凭证；需要时由另一独立供应方核对同市场同事件 | 证实输入与时点；不同交易所价格不能要求完全相同，来源冲突必须解释 |
| 独立复现 | 未参与开发的合格研究者，从冻结的数据、代码、依赖与预期输出从零复算，提交异议与差异 | 证实可复现和部分错误已排除；不是未来收益保证。当前尚未取得外部第三方复核 |
| 未见结果 | 规则冻结后的真正未访问历史留出或新增前向记录，保留事前信号、当时可见报价和全部失败 | 检验泛化。已看2025/2026不能重新切成新样本外；纸面成交仍依赖执行假设 |
| 实际执行 | 另获明确实盘授权后，由交易所/券商原始回报和账单核对费用、滑点、资金费与权益，交独立方复核 | 证实已经发生的经济结果；不保证未来，也不由回测/纸面交易替代 |

此前我们编写的第二条审计代码路径和JSON新进程恢复属于**内部工程复核**，不能称第三方审计。独立复现不等于输入真实，输入真实也不等于未来盈利；任何有限检验都不能证明策略永远有效。外部评审尚未开展，不自动联系或发送材料给他人。
