## 决定与剩余证据

该月0.8x限制实际削减6次初始仓位，使净收益下降1.173个百分点而最大参考回撤未变，但峰值总敞口下降、描述性日夏普升高，不能据此判定它全面无效；8%止损和15%停机均未触发，无法据此评价保护或恢复能力。1x相对3x降低了收益和回撤，属于风险收益取舍，不是单向优劣证明。

以原版NFI作为后续研发基线；自研模块须证明同条件扣费增量，先不扩展因子。逐项比较收益代价和回撤改善后，再选择风险预算，不能先固定约束再把低收益归咎于策略。

当前只能确认这个作者已知月份可复现盈利。策略发布于2026年而测试2025年，存在回顾性调参与选择偏差风险；原始343静态名单、现今交易所规则和可加载数据不等于当时完整可交易池。策略未来函数/递归偏差检查、连续长历史、多行情与冻结后未见结果、盘口执行容量、真实客户资金费与外部复核仍待完成。该月未触发的规则须另有注册压力情景才可评价。总账户年化目标、实盘与容量字段继续为空，不据此开实盘。
