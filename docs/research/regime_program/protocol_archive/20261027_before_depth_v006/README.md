## 1. 专家标准要求主动补做的工作

- **先挑战赚钱的解释。** 谁可能支付，为什么竞争尚未消除收益，资本承担什么风险？交易对手动机若没有直接记录，只能作为假说。价格规律本身不能证明支付者是谁。
- **排查最强替代解释。** 收益是否只是市场多头暴露、降低持仓、少数币/月的偶然贡献、隐含杠杆或漏算费用？分别用方向移除、现金、静态配置对照及实际敞口/集中度检查。对照的实际风险不匹配时明确限制结论。
- **审查数据如何产生。** 退市资产是否消失、同名资产是否被错误拼接、财报和公告是否修订回填、决策与成交是否错用同一时点？原始缺口必须保留，不能自动补零。
- **先写输的条件。** 在看结果前登记最小有用净效应、盈亏平衡成本、风险/容量边界和停止规则；保存失败试验及已看过的数据区间。反证后不换阈值、删年份继续调成阳性。
- **主动找人和新事实来反驳。** 外部复算、未见结果与真实成交分别取证。研究结题可以是反驳或未知，投资收益目标不能因此标完成。

## 2. 原始数据，而非整理好的观点或因子表

| 要判断什么 | 从哪些原始记录开始 | 必须防住什么 |
| --- | --- | --- |
| 价格与容量 | 交易所原始成交及ID、必要成交窗口报价/盘口序列、原始K线ZIP/CSV/校验文件；交易所时间与首次接收时间 | K线足以做初筛，不能据此声称真实队列成交或盘口容量。只采当前机制需要的粒度与窗口 |
| 当时的交易资格 | 上线/退市/换币原公告及历史版本、合约乘数、精度、最小量、状态和保证金规则 | 当前可交易名单不能回填历史，同名代码不能自动拼成同一资产 |
| 经济现金流 | 资金费事件、标记/指数价、收费档位；获授权后使用委托回报、成交、手续费、资金费收入和账户余额/划转 | 公开费率不等于实际到账；开放浮盈、退出准备、基差和资本占用不能漏记 |
| 外部事件 | 央行/交易所/公司首发全文与附件、修订版、预告/实际发布/首次接收时间 | 新闻摘要、情绪评分或事后标签不能证明决策时已知 |
| 港美股复用 | 历史上市/退市与成份变更、未复权价量、公司行动公告、SEC/HKEX原始申报和附件及受理/修订时点 | 标准化财务表只作索引；回到具体原始申报。股票任务独立执行和验收 |

每份必要原始记录保留来源、版本、资产身份、时间单位、时区、币种与可用时点；派生数据可重新生成。同一交易所的归档和API属于同源对照；SHA256只证明文件未变。可从[Binance原始归档入口](https://data.binance.vision/)及[SEC EDGAR申报接口说明](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)定位记录，标准化聚合接口不能替代具体历史原件。

## 4. 除了我们，还有什么能检验结果

| 外部依据 | 能支持什么 | 不能替代什么 |
| --- | --- | --- |
| 数据持有方原始记录；必要时另一独立来源对同市场同事件复核 | 输入、身份和时点的真实性；差异必须解释 | 哈希或同源双接口不能替代独立事实核验 |
| 未参与开发的合格研究者，拿冻结的原始数据、代码、依赖和预期输出从零复算，提交异议 | 结果可复现、部分方法与实现错误被排除 | 我们自己写的第二条审计代码不算第三方审计；复现不能保证未来有效 |
| 规则冻结后的真正未访问历史或新增前向记录，保存事前信号、当时报价和全部失败 | 检验泛化与适用范围 | 重新切分已看历史不能生成未见证据；纸面成交仍依赖模型 |
| 明确获实盘授权后，交易所/券商原始委托、成交、费用及账单交独立方对账 | 已发生的经济收益和真实执行摩擦 | 历史回测、纸面收益和过往实盘都不能证明未来持续盈利 |

验收不是寻找一个人说“对”，而是让不同证据检验不同主张。**当前外部第三方复核和真正未见验证仍未完成。** 不自动联系他人、读取凭证或开展实盘。

每轮交付一份机制判定记录及可复算证据链：假设/最强替代解释 → 原始记录与可用时点 → 冻结规则和对照 → 完整账户/不确定性 → 支持、反驳或未知 → 决定性缺口。必须说明哪项判断因什么证据改变；结果观察后补写的记录只能称历史诊断。
