## 原始报价改变了什么

首组同交易所时间戳的BBO/盘口/ticker显示bid0.0425、ask0.0435、mark0.0433，价格单位BTC；原生指数93370.2USD，另一个forward underlying字段94358.41USD，二者不能混用。以0.1BTC数量作纯单位演示，bid对应396.82335USD、mark对应404.292966USD，相差7.469616USD；不应把mark当可得卖出价格。没有把这段报价执行成交易，也没有收取权利金。

按接收时钟查看的46次跨渠道BBO检查，22次匹配、24次不匹配。24次不匹配可在随后收到、同交易所事件时间戳的book状态找到完全相同BBO，说明本窗口存在跨渠道到达先后差异；后到的book不能用于之前的决策。差异与原件全部保留，不把“最终对上”冒充当时可知或完整执行验证。

## 原始方法与复现缺口

固定v2，保留v1/v2低波动状态解读的区别。作者研究Q/P分布、27日波动率及回溯性聚类；全样本配对距离/Ward标签不能直接充当实时行情路由。BVIX、DVOL与不同期限的已实现方差需要单位/期限映射，差值本身不是可交易利润。原文正文与表1的样本/交易计数存在未解决口径差异，原始面板未取得，不以引用替代核验。

固定作者README明确原始/私有数据不随仓库提供，并说明MATLAB人工阶段和缺少Q_from_IV.R。这里只静态读取README、参数和许可证，没有执行外来代码、装依赖或把tiny-fixture测试当论文复现。当前参数的聚类期限与论文描述也有差别，原论文年代的确切代码映射未验收。UWA2020数据属于另一篇预测研究：元数据可读，文件前缀403，保留失败，不替代本论文原件。GitHub REST限流403后，用同一公开仓库一次正常匿名Git读取固定版本；没有认证或代理变更。
