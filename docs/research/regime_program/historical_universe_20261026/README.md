# 历史币池已扩展，交易资格和盈利仍未验证

已采集并独立读取21,357份官方月度日线ZIP及对应SHA256，覆盖860个历史候选合约、636,990条日线。268个合约曾进入固定周频资格预览，其中228个在原40币池以外。没有新增收益账户，也没有更新多策略总账户20%／30%目标的实际值。

原40币池按事后可见币种固定；新样本先枚举全部归档名称，再按过去成交额与观察年龄判断。两者覆盖范围不同，旧账户结果保留，不把本次采集冒充旧结果已经消除存续偏差。

## 源异常与独立核验

| 源检查项 | 数量 |
| --- | ---: |
| 成交额超出高低价与总量可解释范围 | 24 |
| 主动成交或交易笔数字段冲突 | 8 |
| 首末观测之间缺失日期 | 323 |
| 与既有五分钟聚合不一致的合约日 | 121 |

官方SHA256校验通过仍可能存在源字段冲突。原值、缺日与非完整日均保留；价格／流动性字段不合格的日期不用于候选资格，辅助字段单独标记，未补价格或截尾收益。异常计数可在同一行重叠，不应相加当作独立样本。

原始严格摄取留下8个显式失败月，不覆盖该目录；独立CSV解析补取这些已列示档案共16次请求，仍要求官方SHA256和原始ZIP大小一致。日线成交额要处于最低／最高价格×基础成交量之间，容差为max(0.01USDT,1e-6相对误差)，源字段互相冲突时不改成“合理值”。例如ARBUSDT 2023-09-19官方日线出现主动买入基础量大于总量，以及成交额越出价格与量的可解释范围；该币不在原40币池中，不能据此声称旧40账户数值被改写。

独立NumPy算术复算全部366次候选预览，并在2021／2023／2025三个截止点放大真实未来成交额检查过去窗口；价格／量异常与缺日保留，不截尾、不补零。原40币五分钟完整日聚合另作独立区间对照，发现121个合约日存在差异；差异和日期保存在[验证收据](verification.json)，有差异就不宣称全量一致。即使源校验和一致，也不能据此推断经济数据正确。

## 新公开来源只作固定版本参考

[OctopusTakopi/funding-rate-alpha](https://github.com/OctopusTakopi/funding-rate-alpha/tree/cf9f87c01d3165bbc3bf34438baee289d248ffca)为MIT个人研究。其原始大体积资料未随仓库发布；已检查代码里未来收益非空的成员筛选、默认收益截尾和持仓缺失零贡献处理。动态历史档案和分开检查资金费／价格损益值得参考，源码收益不能作为我们的完整账户证据。

[bryanvine/alpha-research](https://github.com/bryanvine/alpha-research/tree/17b8b5e1c79af194f733544517d82e3cf12c2259)提供纯资金费横截面假设，但采用现货日收益代理永续价格腿；默认5个观察日再平衡与固定周一不同，分位阈值在全部信号相同时可能令多空集合重叠。未核实可复制代码许可，因此仅作来源审阅，不把代码引入统一因子库。两份较新的个人研究都不等同于成熟框架或已验证高收益来源。

完整固定commit、文件SHA和定位见[来源审阅](source_review.json)。所有外部源码仅静态读取，没有执行、安装其项目或访问其自述中的私人数据卷。官方归档来源仍是Binance，原始CSV／ZIP／CHECKSUM、清单分页和当前元数据分开存证。
