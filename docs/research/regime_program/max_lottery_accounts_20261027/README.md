## 为什么研究这一命题

新取得的Grobys/Junttila2021大学原始PDF（封存200响应）采用前一周7个日对数收益、等权五分组；表1的高减低为负。它与既有Ozdamar等2021的28日MAX正向结果在样本、时钟和权重上不同，不能归因为某一个参数。前者明确指出原现货样本做空受限，并把实际可投资长仓盈利留给后续研究；其对数因子差额不是资金账户收益。原始面板/代码不可得，日期/观测数还存在未解决的索引差异，本轮不称原法完整复现。新发布PDF接口301未跟随，既有正向来源原始200HTML保留。

本轮采用当前可研究永续的明确本地适配，真实资金费和两腿费用落账。信号只用前8个完整连续日收盘，形成7个日收益；周一UTC00及初始日决策，最低MAX等权做多、最高等权做空；普通累计7日收益反转用同样构造。候选和对照最多12仓，以容纳前30池两端五分位，gross仍0.8；没有扩大风险预算。继承冻结180日/流动性/身份分段的共同机会集，不删缺市值币。支付者或过度定价只是假说，本轮也没有识别其因果行为。

## 证据与停止决定

352个真实形成书逐项由原始8日价格复算，6组未来扰动未改过去信号，5项针对性测试通过。两份来源完整目标在收益前精确一致、执行档案相同，因此8个逻辑源/策略/成本条件只运行4条实际账户并保留源别名；不把它们算成独立试验。四条逐笔现金/持仓/实际资金费/净值内部审计通过，最大净值差3.09228198603e-11USDT。固定成交路径的价格、资金费、手续费和滑点分解另附：MAX7两成本价格分量分别−698.79／−615.62USDT，资金费仅+0.93／+0.94USDT，价格腿在费用前已负；它不是零费用重跑。

源码、费用、阈值、时钟和输入先登记再评估，已有源码和旧金融文件未覆盖。新的每策略进程重启没有执行；当前阴性必要经济门槛已经足以拒绝本分支，不借旧引擎恢复测试宣称新策略交接资格。没有触发容量追加，1%K线参与率不是真实盘口容量；没有第三方复核、真正未见或实盘收益。股票需独立交易日历、方向与账户验收。

**停止MAX7方向／窗口／跳日和风险参数搜索。** 本轮否定的是这份本地政策的必要经济条件，不能推导所有彩票需求或所有行情下的MAX无效。保留相反原始研究与当前阴性结果；下一经济命题必须有新的原始方法及决定性反证，不能靠翻转本次亏损组合、删年份或调杠杆求通过。总目标仍需要两个不同有效机制、共享资金组合、容量与外部/未见证据，目前均未完成。
