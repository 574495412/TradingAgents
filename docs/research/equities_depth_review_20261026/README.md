# 原始申报核对与既有个股机制归因

本轮没有增加策略、股票、参数或经济账户。沿用已封存的四个高成本个股账户，深入核查原始输入、收益来自哪里、风险参数是否实际兑现。**50%扣费年化、回撤≤15%的挑战仍未达标；没有新增准入策略，G7外部独立复核与G8真实前向证据仍未取得。**

## 1. 从网页传输版追到完整申报原件

首次Arelle尝试暴露了来源问题：SEC直接返回的EXAS财报网页含Akamai安全脚本和不符合XHTML的附加属性；另有依赖文件503/超时和初始插件路径错误。原失败文件及日志保留，没有删除脚本、删事实、跳过DTS或关闭校验来取得通过。

改从SEC **complete submission `.txt`** 获取完整申报，按[SEC PDS规范](https://www.sec.gov/files/info/edgar/specifications/pds-dissemination-spec030314.pdf)识别`DOCUMENT/TEXT/XBRL`封装；记录父文件SHA、文档字节起止位置及子文件SHA，仅去除申报传输封装，不改发行人文件内容。160份主文档/模式/依赖文件已逐一反向核对：子文件字节就是父文件记录区间。

直接网页与完整申报中主文档的字节，20份均不相同。**本轮证明的是实际消费的45项数值一致，不是全文所有字节差异都已解释或两个载体完全等价。** 两个载体都来自同一个SEC，不能算两个独立数据供应商。

初步只统计区间内决策时有19个年度版本；把2022年12月30日形成、用于首个交易日的决策计入后，完整消费集为**20个版本**。名单由冻结的决策追溯表机械确定，没有按校验成功与否挑选。

| 原始输入检查 | 结果 | 能支持的结论 |
| --- | ---: | --- |
| 完整申报中的接受时间与SEC submissions API比对 | 20/20一致 | 美东原始接受时间、UTC转换及额外1小时延迟一致 |
| 实际消费决策的可用时间检查 | 121条通过 | 被用到的原始年度数据未早于相应可用时刻 |
| CIK、报告期、USD单位、无分部维度、有效数值的精确匹配 | 45/45一致 | 本轮消耗的年度因子输入未发生数值替换 |
| Arelle原始XBRL/iXBRL及DTS校验 | 20/20通过，错误0 | 原始文件在本次标准工具配置下可解析和校验 |
| 解析的全部事实数 | 32,682 | 工具加载范围；不是独立经济样本或获利证据 |

Arelle固定为`2.47.3`。SEC维护的转换插件采用`Arelle/EDGAR`提交`4891c4c9889c77af247428ceff4fa7cc52d534ea`下的`transform/`，保留CC0许可、源码及SHA。依赖wheel在隔离环境固定，工具不读取应用配置、不运行财报公式、不导入TradingAgents的自动dotenv初始化器。完整申报、发行人依赖和标准分类模式均保留以便复核。

这覆盖本次消耗的年度输入，不覆盖所有季度、自定义标签、全市场股票身份、首次业绩公告时间、会计真实性或SEC EFM全面合规。**使用外部维护工具仍是本项目执行的核查，不能替代独立核查方、独立数据供应商或审计意见。**

证据：`results/research/equity_arelle_review_20261026_v002/`；摘要见[original-input-review.json](original-input-review.json)。最初v001批次因解析了虚拟环境Python符号链接而启动基础解释器，20次均在工具导入处失败、数值核对数为0。原失败目录保留，v002增加运行时预检并保留虚拟环境入口；没有把失败尝试记成已复核或新的经济试验。

## 2. 动量盈利高度集中，尚不能证明独立优势

审计对象仍为`US_french_mom_12_2_10000_15bps`：10,000美元，2023年1月至2024年6月26日，每边15bps不利滑点加原费用。对焦这个已看过的账户是事后诊断选择，不能重新声称事前选中赢家或独立样本外。

没有重跑策略或改变持仓。对四个冻结账户共14,880条逐日股票记录，分解：

> 当日权益变化 = 前一日库存×隔夜价差 + 开盘成交后库存×日内价格变化 + 实际股息应收 − 费用 − 滑点。

卖出资金从未结算转为可用现金不产生利润；每只股票再由净交易现金流加期末库存盯市核对总贡献。动量账户逐日对账最大误差约`2.68e-12`美元。

| 动量账户损益来源 | 美元 |
| --- | ---: |
| 隔夜价格变化 | +2,289.84 |
| 日内价格变化 | -1,108.43 |
| 佣金及法定费用 | -38.57 |
| 不利滑点 | -105.02 |
| 股息应收 | 0.00 |
| 净盯市损益 | **+1,037.82** |
| 额外期末退出准备 | -15.53 |
| 扣退出准备后损益 | **+1,022.29** |

COIN贡献`+2,899.65`美元，EXAS贡献`+628.05`美元；其余主要负贡献为TSLA `-882.57`、PATH `-740.77`、CRSP `-688.40`美元。COIN占所有正贡献的约82.2%，除COIN以外合计为`-1,861.84`美元。去掉最强5个交易日的贡献后，余下日损益合计`-3,115.91`美元。

这些“减去贡献”只是脆弱性算术，不是删掉COIN或交易日后可以实际执行的另一账户，更不能用于反向选股。趋势机制本来就可能依赖少数大赢家，集中性本身不能否定动量；但目前不足以支持“稳定分散收益源”或“已经可与加密独立叠加”的说法。COIN相关的风险机制还需共同期间的原始数据验证，不能仅因资产标签不同就算两个独立机制。

全部股票、保留库存、闭合周期与成本见[stock-attribution.json](stock-attribution.json)。

## 3. 风险暴露与不确定性

使用原有已哈希封存的SPY、QQQ作为风险控制，不是新增ETF策略。控制变量为SPY总回报及QQQ减SPY回报，零现金利息；它们是毛风险因子，不是可执行的净收益对照账户。

在372个交易日上做固定OLS和Bartlett HAC lag5、有限样本修正。并对动量减同池等权账户的逐日净收益差做固定20日圆形分块bootstrap，2,000次、种子20261026。没有搜索基准、滞后或区块长度。

| 描述量 | 点估计 | 95%描述区间 |
| --- | ---: | ---: |
| 控制市场/科技后的动量日截距 | -6.95 bps/日 | -24.10 至 +10.21 bps/日 |
| 动量减同池等权的平均日净收益差 | +1.88 bps/日 | -7.46 至 +11.06 bps/日 |

两者区间均跨零。现有6.80%诊断年化**不能据此解释为已证明的独立alpha或稳定超额收益**；也不能从区间跨零推断所有动量策略无效。原实验没有预登记最小alpha效应和统计功效，当前样本仅8个闭合周期；全部历史已经看过，这些区间未经选择校正，不是前向预测或因果识别。

同池等权并未与动量严格匹配风险；配对收益差仍是描述量。线性回归也不能替代真正的同风险、可执行反事实实验。独立矩阵实现重新计算OLS/HAC5，系数、标准误和区间与statsmodels最大差约`3.1e-14`；这只是方法算术复核，不能提升证据等级。

动量平均收盘股票敞口52.45%，最高84.54%，有32个收盘日超过80%；单只股票收盘权重最高35.12%。原因应按原始整数股、价差、目标漂移和5%不交易带解释。**80%是目标权重约束，不能称为已实现的持续硬敞口上限。** 本轮不修改风控规则来重跑好看的结果。

研究账户收盘最大回撤28.15%，日低价包络28.99%，已经超过15%目标。包络仍不是同步盘中回撤，也没有取得真实成交/容量认证。

完整描述结果见[exposure-diagnostics.json](exposure-diagnostics.json)。

## 后续：选择记录与功效规划

本次只核查四个现存股票研究目录的180条完整账户结果：早期108、ETF探索56、本目标ETF8、个股8。前164条是旧计划复用，当前计划仍执行16/24；**180是观察到的账户记录数，不是独立试验数，也不证明完整搜索史已经取得**。26条是显式现金策略；按原始十进制权益的精确有理比率、时间戳与币种比较，净值路径严格不同的有160条，但它们同样受共享市场、策略、成本、资本和区间影响，不能拿160代替独立试验数量。

还有一次个股v001未完成尝试：有注册和协议，账户结果/状态均为0，无最终摘要。封存费用源代码当时仅允许ETF，和个股域不兼容；缺少终止异常日志，不仅凭目录推断确切报错。记录该尝试，不将它冒充额外8个已完成账户，也不从选择史中删去。现个股372个收益日期全部落在早先US市场账户结果的日期内；这支持“市场时期已有历史研究覆盖”，**不证明研究者曾查看全部个股结果，更不认证未来样本外**。全部180份结果的前向OOS标记仍为false。

[观察到的选择链](selection-lineage.json)与结果逐一绑定，原始逐账户清单在`results/research/equity_selection_power_20261027_v002/observed-records.json`。该范围没有穷尽此前人类/模型选择、放弃的候选、来源和时间窗口等影响，DSR/PBO保持空值。本次不使用相关试验数的猜测输出“选择校正后显著”。

在计算前保存[规划假设](selection-power-plan.json)，对四组明确的假设情景使用非中心t分布。设日收益独立同分布正态、年化频率252、单次预先锁定的单边5%检验、目标功效80%；原假设与备择以真实年化夏普表示，均不是现策略的已知夏普。统计量为`T=(Z+lambda)/sqrt(V/df)`，`df=n-1`、`lambda=S*sqrt(n/252)`；取原假设分布95%临界值，在备择分布计算拒绝概率。以整数二分寻找满足80%的最小n，同时用正态与卡方混合积分核对原假设尾概率和备择功效，截断尾质量不超过2e-12。[SciPy原始方法说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.nct.html)已保存，工具版本见注册。

| 假设情景：原假设→备择夏普 | 252日时功效 | 该模型下80%功效所需日数 | 按252日折算年数 |
| --- | ---: | ---: | ---: |
| 0→1 | 25.86% | 1,560 | 6.19 |
| 0→1.5 | 44.08% | 694 | 2.75 |
| 0→2 | 63.67% | 391 | 1.55 |
| 1→1.5 | 12.54% | 6,254 | 24.82 |

**这不是新验收期限、真实收益预测或策略选择结果。** 它只展示“一年/100笔”不能普遍代替统计功效。未知的真实效应、序列相关、厚尾、制度变化和多重选择都没有被这些理想模型认证；没有据此选最容易过关的一行。夏普检验不认证净CAGR50%、最大回撤15%、容量或真实资金。12个月及既有100完整周期仍是原最低要求，G3/G7/G8继续未通过；真实经济最小效应和前向功效计划需要在新的评价前锁定，不补写为原历史实验的事前假设。
